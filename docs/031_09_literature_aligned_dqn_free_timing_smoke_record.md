## Interpretation boundary

This smoke can only decide whether the literature-aligned DQN setting is promising enough for longer/free-timing work. It does not establish cross-seed, cross-year, or exact-paper reproducibility.

## Result interpretation

- The literature-aligned DQN reconstruction improved over the earlier free-timing PPO/random early-dump baselines on SY2014 seed0: final grain yield was 10794.46 kg/ha, higher than the 031_03 random baseline and 031_08 PPO reward-v3 smoke, but still below the fixed-timing `uniform_spread` / `expert_window_budget` reference of about 10908.60 kg/ha.
- It did not reach both I160/N250 caps by DAP10. This is an improvement over the PPO reward-v3 early-dump failure.
- It still saturated the seasonal caps overall: total irrigation 160 mm and total nitrogen 250 kg/ha.
- Deterministic non-zero actions were:
  - DAP1: I24/N0
  - DAP2: I0/N160
  - DAP37: I18/N90
  - DAP43-48: I18/N0 each day
  - DAP49: I10/N0
- Therefore, this smoke is a partial positive signal for DQN relative to PPO/random under the current fully free timing setting, but not a final solution. The policy still shows action-aliasing/cap-clipping behavior because it repeatedly requests action 19 (I18/N160) after the nitrogen cap has already been reached.
- Next decision should not be full-site expansion. A small follow-up should test whether the same literature-aligned DQN benefits from a minimal operation interval hard mask or from a reduced action grid that avoids repeated clipped N160 requests.
