# 031_10 Literature-aligned DQN with 7-day minimum interval smoke record

## Scope

- SYA2014 seed0 only.
- Algorithm: SB3 DQN with the same literature-aligned reconstruction as 031_09.
- Single changed variable from 031_09: same-resource minimum operation interval is 7 days instead of 1 day.
- Free daily timing remains enabled; expert DAP windows are not used.
- Training timesteps: 5,000.
- Action grid: irrigation `{0,6,12,18,24}` mm x nitrogen `{0,40,80,120,160}` kg/ha.
- Reward: terminal `0.158*Y - 0.79*N - 1.1*W`; non-terminal `-0.79*N - 1.1*W`.

## Interpretation boundary

This is a one-seed, one-site-year smoke. It can test whether a 7-day hard interval reduces early dump/action clipping relative to 031_09, but it cannot establish cross-seed or cross-year success.

## Result interpretation

- 031_10 is a strong positive smoke relative to 031_09:
  - final grain yield increased from 10794.46 to 10955.97 kg/ha;
  - irrigation decreased from 160 to 72 mm;
  - nitrogen remained at 250 kg/ha;
  - simple profit increased from 9384.46 to 9633.97.
- It also exceeded the fixed-timing `uniform_spread` / `expert_window_budget` reference yield of about 10908.60 kg/ha while using much less irrigation.
- The 7-day hard interval reduced continuous irrigation/action-aliasing behavior. Deterministic non-zero actions were:
  - DAP1: I0/N120
  - DAP2: I12/N0
  - DAP8: I18/N130
  - DAP15: I6/N0
  - DAP95: I6/N0
  - DAP113: I12/N0
  - DAP120: I18/N0
- Important caveat: nitrogen still reaches the seasonal cap by DAP8. Therefore, this is not yet a final agronomic conclusion; it is a promising algorithmic smoke showing that the interval constraint helps DQN escape the 031_09 continuous-irrigation pathology.
- Next step should be a seed stability check under exactly this 031_10 configuration, not immediate all-site expansion or further reward/network tuning.
