# 021_15 SY2014 checkpoint管理时机与物候对齐离线审计

## 1. 目的

021_14发现，相同季节总量I120/N300可以对应11046和8120 kg/ha。这个差异可能来自真实农学施用时机，也可能与训练策略漂移、预算裁剪或观测不充分有关。本轮不训练、不调用DSSAT，只读取已有确定性评价和DSSAT物候输出，先描述时机证据。

## 2. 输入与边界

- 未缩放：021_10，SY2014 IC=2 seed1，探索率0.70；
- 缩放0.1：021_14，同站点、年份、IC、seed和探索配置；
- checkpoint：5K、10K、15K、20K、25K；
- 管理事件：各checkpoint `eval_daily.csv`的实际执行水氮；
- 物候：对应`OVERVIEW.OUT`最后一个DQN结果块；
- 没有新训练或DSSAT运行；
- 描述性对应不写成因果，不直接宣布Markov缺陷已确认。

## 3. DSSAT物候

两个协议、全部checkpoint的物候日期一致：

| 阶段 | DAP |
|---|---:|
| 出苗 | 9 |
| 幼龄期结束 | 34 |
| 花芽分化 | 44 |
| 75%吐丝 | 89 |
| 灌浆开始 | 99 |
| 灌浆结束 | 136 |
| 成熟 | 139 |

因此各checkpoint产量差异不能归因于“我们使用了不同的物候分界”。

## 4. 关键同总量对照：10K

| 指标 | 未缩放10K | 缩放10K |
|---|---:|---:|
| 产量（kg/ha） | **11046** | **8120** |
| 灌溉总量（mm） | 120 | 120 |
| 灌溉事件数 | 8 | 8 |
| 灌溉加权平均DAP | 25.5 | 26.1 |
| 施氮总量（kg/ha） | 300 | 300 |
| 施氮事件数 | 4 | 3 |
| 首次—末次施氮DAP | 69–90 | 94–109 |
| 施氮加权平均DAP | 78.3 | 101.7 |
| 吐丝后施氮 | 50 | **300** |
| 灌浆开始后施氮 | 0 | **200** |

两者灌溉次数、总量和加权平均时点非常接近；最显著差异是氮肥时机：

- 未缩放10K：DAP69、76、83、90，主要位于花芽分化至吐丝前后；
- 缩放10K：DAP94、102、109，全部在吐丝后，其中200 kg/ha已进入灌浆期。

这是一条比“Q值在抖”更具体的行为证据：低产checkpoint实际执行的是明显更晚的施氮方案。

缩放轨迹的两个低产点（10K和20K）都具有明显晚施氮特征；两个高产点（5K和25K）则把全部氮放在吐丝前。15K介于两者之间。这个对应关系支持“时机是真实的重要变量”。

不过，未缩放25K即使有部分晚施氮仍保持10794 kg/ha，说明不能把全部产量差异简化成一个单一DAP阈值，也不能根据10个checkpoint建立普遍因果规律。

## 6. 如何解释“训练不稳定”与“真实农学信号”

二者并不矛盾：

1. DSSAT对施氮时机产生真实响应，是农学信号；
2. DQN在不同checkpoint间不断切换早施、晚施和少施策略，是时序策略质量不稳定；
3. 因此产量大幅波动不是DSSAT随机噪声，也不是只由季节总量决定，而是网络动作排序变化通过真实作物机理转化成产量差异。

本轮不能确认：

- 晚施氮是全部差异的唯一原因；
- 预算裁剪直接造成了晚施；
- 缺少剩余预算/操作间隔信息已经被证明是根因；
- 增加观测变量一定能解决问题。

## 7. 结论

1. “相同I120/N300但产量不同”主要伴随非常显著的氮时机差异，而不是物候分界或灌溉总量差异。
2. 缩放10K把全部N放到吐丝后、其中2/3放到灌浆期；未缩放10K主要在吐丝前完成施氮。这为8120与11046的差异提供了农学上合理的解释。
3. reward缩放没有稳定住时序策略；它只是改变了网络数值更新和策略经过各时序方案的路径。
4. 现有证据支持“需要显式关注时序状态”，但尚不能直接宣布Markov修复方案正确。

## 8. 下一步建议

如果需要进一步建立因果，可做一个很小的确定性DSSAT时机交叉实验：固定同一套灌溉，只交换10K高产/低产的施氮时点，保持N300不变。该实验只需少量前向模拟，但属于新实验，应在用户确认后单独立项。

若当前目标是修DQN而非继续证明农学机理，则可把观测空间修复正式提交给用户/导师讨论：增加剩余水预算、剩余氮预算和距上次操作天数。它改变环境定义，必须单独实施，不能再与reward缩放同时修改。
