# 025_00 确定性水氮优化正式协议与 SY 跨年准备度审计

## 1. 目的

冻结 021–024 学习式方法调试线，建立正式的 DSSAT 约束确定性优化路线。首先区分：

- **单年 oracle**：使用该年完整天气搜索，只证明该站点年份的可达上界；
- **跨年固定策略**：只在训练年选择管理方案，将方案原样用于未参与选择的年份，才构成跨年验证。

本任务只冻结协议并审计 SY2014→SY2012 的输入准备度，不运行 DSSAT、不重新搜索候选。

## 2. 科学目标

候选必须在同输入条件下，与 `official extension expert` 和 `DSSAT auto` 中更严格的基准比较：

1. 产量不低于两者较高值；
2. `WP_ET = yield / ET / 10` 不低于两者较高值；
3. `PFP_N = yield / applied_N` 不低于 official expert；
4. 资源投入不超过预注册预算；
5. 不允许晚期无效施氮；
6. 同时报告与 recorded/farmer 的差异，但 recorded 不替代 official expert。

判定采用可行性优先的词典序，不把产量、水和氮临时压成可调加权和。

## 3. 两层验证

### 3.1 Oracle 层

- 每个站点年份可独立使用完整天气搜索；
- 结果只能称为 retrospective oracle / deterministic upper bound；
- 不得称为可部署策略或跨年泛化。

### 3.2 固定策略层

- 训练年：选择候选方案；
- 验证年：不重新优化、不移动阶段、不改变总量；
- 只允许按目标年份播种日重新计算相同 DAP 偏移；
- 验证年 expert、auto、null 与候选必须使用同一 WTH、SOIL、CUL、IC 和处理行；
- 若固定方案失败，不得在验证年重新选候选后仍称跨年成功。

## 4. 第一组验证

- 训练/选择年：SY2014，IC=2；
- 候选来源：022_01 已有18个严格成功固定阶段方案；
- 独立验证年：SY2012，IC=1；
- SY2012 不参与候选筛选；
- 下一任务先做输入provenance与null/recorded/auto/official expert前向验证；通过后，才允许将18个方案原样迁移到2012。

## 5. 本任务审计项

- SY2014 18个严格候选及其动作计划是否完整；
- 当前SY MZX是否同时包含2012 IC=1和2014 IC=2；
- 2012 WTH、SOIL、CUL是否存在；
- 2012历史前向结果是否仅可作为准备度证据；
- 当前站点YAML是否已正式注册2012；
- 2012同输入四基线是否齐全；
- 输出协议YAML、准备度表和下一步硬边界。

## 6. 停止规则

- 本任务 DSSAT 调用0次；
- 不修改 IC、MZX、WTH、SOL、CUL；
- 不修改站点YAML；
- 不启动18候选迁移；
- 若输入文件或2014候选缺失，判失败；
- 若输入存在但正式配置/基线未完成，判“协议可用、需先做输入基线验证”，不得跳过。
