# HLA 新品种参数候选年份筛选 prompt

## 背景

HLA 2004 在 IC=1 和新 HY0006 品种参数下仍表现为极端干旱/极端受限年份：null 情景籽粒产量为 0，记录管理也不能充分恢复产量。因此，在正式重启 PPO 水氮联合优化前，需要先筛选更适合作为优化示例的年份。

当前不进行 PPO 训练，只做低成本 PDI/gym-DSSAT forward check。

## 目标

从 HLA 候选年份中初步判断哪些年份同时满足：

1. null 情景存在一定水分/氮素胁迫；
2. 管理措施或 DSSAT 自动灌溉能改变胁迫或产量；
3. 作物能正常完成生长季；
4. 不像 2004 那样极端到 null 籽粒产量为 0；
5. 有足够优化空间，适合作为后续 PPO 水氮联合优化的候选年份。

## 候选年份

本轮只跑小规模筛选：

- 2007：有实测管理记录，且是校准年份之一；
- 2010：已有 IC=1 年度诊断显示 null 与自动灌溉差异较大；
- 2015：已有 IC=1 年度诊断显示 null 与自动灌溉差异较大。

注意：2010 和 2015 暂未找到真实 recorded/expert 管理记录，本轮只比较 null 与 DSSAT auto，不虚构 expert 管理。

## 输入口径

- 运行环境：Docker 容器内 PDI/gym-DSSAT，DSSAT 4.8.0 口径；
- 品种参数：使用用户最新校准的 `input_corrected_package/MZCER048.CUL`，不使用 `my_data/MZCER048.CUL` 的旧 HY0006；
- 初始条件：沿用已有 `hla_ic1_yearly_diagnostics_2004_2023` 中 IC=1 年度输入文件；
- 站点：HLA；
- 情景：
  - null：无灌溉、无施肥；
  - dssat_auto：DSSAT 原生自动灌溉/自动施肥尝试；
  - recorded：仅当真实记录管理文件可用时使用，本轮不为 2010/2015 人为构造 recorded。

## 输出

保存：

- 每个 case 的 input 文件夹；
- PDI 临时输出快照；
- daily CSV；
- summary CSV；
- 事件 CSV；
- 高对比过程图：降雨、灌溉、施肥、WSPD、NSTD；
- 产量/生物量柱状图；
- 实验记录 MD。

## 判读原则

这一步只筛选候选年份，不宣布 PPO 优越性。

如果某年份：

- null 已经接近 recorded/auto，说明优化空间小；
- auto 能显著降低 WSPD 并提高产量，说明水分管理有响应空间；
- null 有氮胁迫但自动施肥仍不触发，只记录为 DSSAT 原生自动施肥机制问题，不继续在此轮深挖；
- 生长季能正常完成且产量不为 0，则优先作为后续 PPO 小规模测试候选。
