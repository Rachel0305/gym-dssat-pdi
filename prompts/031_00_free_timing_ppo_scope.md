# 031_00 Free-timing PPO scope and constraints

## Purpose

Start the new advisor-facing reinforcement-learning line:

> RL chooses timing and dose freely within agronomic safety constraints.

This task only freezes the scope and constraints. It does not train PPO and does not run DSSAT.

## Why this is not the old stage-window PPO

Old stage PPO was a dosage-only ablation: the agent acted at expert-like DAP windows.

New free-timing PPO removes that fixed expert-window constraint:

- decision opportunity: every simulated day during the management season;
- the agent may choose no-op, irrigation, fertilization, or combined operation depending on the action design in the next implementation task;
- actions are no longer restricted to expert DAPs.

## Weather-year scope

Use the 030_00 weather usability table.

Rules:

- use only station-years with `selected_for_next_rl=yes`;
- exclude years before 2000;
- therefore LC1999 is not used, even though its weather is usable;
- LC1998 remains excluded because weather has unresolved missing sentinel values;
- HLA2010 must use the corrected weather copy generated by 030_00.

## Operation interval decision

Keep a minimum operation interval in the first formal free-timing PPO line:

- minimum 7 days between non-zero field operations;
- this is not copied from expert timing;
- it is an operational feasibility constraint to prevent daily repeated irrigation/fertilization artifacts;
- timing is still free because PPO can choose any eligible day, not only expert windows.

If the advisor demands fully unconstrained daily operation, treat `min_interval=1` as a later ablation, not as the first formal run.

## Other safety constraints to carry forward

Freeze these as first-pass safety limits unless a later pre-registered task changes them:

- no fertilization after DAP 90;
- seasonal irrigation cap and nitrogen cap must be explicit in the next training config;
- daily maximum irrigation/fertilization must be explicit in the next training config;
- N=0 cases must not compute PFP_N by division by zero; mark PFP_N as NA.
