# 022_00 SY2014 生育阶段型 DQN：预注册设计与离线单元测试

## 1. 任务定位

021_48 后冻结旧的“日尺度 + 5-step + 稀疏终端奖励”诊断线。本任务启动新的 022 结构线，但只完成：

1. 证据审计；
2. 阶段动作、回报目标和停止规则的预注册；
3. 纯离线单元测试。

本任务不调用 DSSAT、不训练模型、不改 IC、不覆盖旧结果。

## 2. 直接继承的 021 系列结论

以下结论不在 022_00 重复验证：

1. **目标错位（021_43）**：`max(0,Y-null)-I-5N` 可能偏好低于 expert 产量的低氮策略。新结构保留 021_44 推导的 feasibility gate bonus，使“先达到 expert 产量门槛、再比较资源效率”成为显式目标。
2. **旧传播与拟合限制（021_47/48）**：旧结构中 target 在 1K 内冻结、5-step 标准 bootstrap 不能逐段覆盖远期动作，终端 value 在被充分采样后仍几乎未拟合。022 使用最多 6 个阶段 transition 和 terminal-complete return，直接针对该限制。
3. **旧在线结论的适用范围（021_35–45）**：坍缩/恢复是在 `1K + fixed-target` 的短期诊断中观察到的，不能冒充完整 DQN 动力学。
4. **施氮时机因果效应（021_16）**：相同 I120/N300 下约 2.91 t/ha 差异几乎全部由施氮时点造成，因此阶段动作不是装饰性改动。
5. **现有观测信息（021_17）**：实际25维输入已经含精确 DAP、累计 I/N、`istage`、`vstage`。022_00 不重复添加这些字段；距上次操作时间也暂不加入，因为固定阶段间隔均超过7天。

## 4. 动作与约束

- 保留冻结的9动作：`I∈{0,15,30}` × `N∈{0,50,100}`。
- 季节预算：I≤120 mm，N≤300 kg/ha。
- 每个阶段最多执行一个动作；阶段之间底层DSSAT逐日推进并强制no-op。
- 所有请求动作先按剩余预算裁剪并记录请求值/执行值。
- DAP110已晚于SY2014吐丝DAP89，只允许动作0/1/2（N=0）；必须使用 action mask，不允许把含N动作静默裁剪为N=0后制造动作混叠。
- 阶段间隔最小15天，天然满足旧的7天最小操作间隔；不得再额外添加间隔惩罚。

## 6. 回报与Q目标

保持站点本地基准：null=5408 kg/ha、official expert=11077 kg/ha。

阶段即时成本：

```text
r_stage = -1 * I_stage - 5 * N_stage
```

终止价值：

```text
r_terminal = max(0, Y_final - 5408) + 1620 * 1[Y_final >= 11077]
```

其中1620=`1×120+5×300`，来自021_44的最大预算成本上界，不重新拟合。

对一季最多6个stage transition，使用 `gamma=1` 的 terminal-complete return：

```text
G_t = sum_{k=t}^{T} r_k
loss = Huber(Q_online(s_t,a_t), G_t)
```

这是**唯一的 agent Q目标**：

- 不同时保留1-step TD；
- 不同时叠加另一个5-step loss；
- 不使用target network bootstrap；
- 因此不会重复021_27中完整return与1-step TD方向冲突、等权抵消的问题。

方法学命名必须诚实写为“stage-based DQN-style Q network with terminal-complete Monte Carlo targets”，不能冒充未修改的SB3标准DQN。

## 7. target network决定

022阶段的每条训练transition都来自已经终止的完整季节，`G_t`不含bootstrap，所以target network不参与Q target计算。不存在“1K内继续冻结还是周期同步”这个混淆：本结构明确不使用target network来构造训练目标。

## 8. 训练前强制门槛

022_00通过后也不得直接训练。022_01必须先用固定阶段点做低成本确定性可行性搜索。

**主科学判据沿用021_18原始预注册口径**：

- HWAM≥11077 kg/ha；
- WP_ET不低于同输入official expert与auto的较高值；
- N>0时PFP_N≥official expert；
- I≤120 mm、N≤300 kg/ha；

若固定阶段动作空间不存在达标方案，停止DQN训练；不得为了结果事后移动阶段点。只能回到方法设计层面重新审批。
