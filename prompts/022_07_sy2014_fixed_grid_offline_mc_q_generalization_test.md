# 022_07 SY2014 固定网格离线 MC-Q 场景留出泛化测试

## 1. 依据与问题

022_06 表明：预算动作别名存在，但 N300 是 DAP65 前后真实执行形成；更主要的诊断信号是固定支持集内部 Q 排序仍不稳定。下一步不能直接增加在线训练，而应先回答更基础的问题：在不调用 DSSAT 的离线条件下，当前 25→64→64→9 网络能否从固定网格的已执行动作及完整季节 Monte Carlo target 中学到可泛化的价值关系。

## 2. 唯一实验内容

使用 022_03 已保存的 48 个完整场景、288 条 transition：

- 以完整 scenario 为单位划分训练集和测试集，禁止同一场景跨集合；
- 测试集固定为 12 个场景，训练集 36 个场景；
- 划分算法只使用场景名称、阶段动作覆盖和成功/失败标签，不读取 target 数值；
- 要求每个阶段-动作组合在训练集和测试集中都至少出现一次，且两集合均包含成功和失败场景；
- 对 recorded action 的 scaled terminal-complete MC target 做 SmoothL1 全批量监督；
- 网络、观测标准化和学习率保持 022_02/022_03：25→64→64→9、ReLU、Adam 1e-4；
- 固定 2000 次 full-batch update；离线种子 0/1/2；
- 不做在线交互、不调用 DSSAT、不加入 PER/demo/target network/TD bootstrap/reward 修改。

## 3. 对照与评价

每个 seed 同时保存：

1. 同初始化但未训练网络；
2. 2000 次更新后的离线 MC-Q 网络。

测试集评价：

- recorded-action MAE、RMSE、Spearman；
- 相对“训练集 target 均值常数预测”的 MAE 改善；
- 六阶段内平均 Q 与测试集经验平均 target 的 Spearman；
- DAP1 48 个原始观测已被 022_06 证实为同一状态，测试集 DAP1 动作排序作为最强排序证据；
- DAP30 以后不同动作来自不同历史状态，只作描述性聚合，不写成因果反事实。

## 4. 预注册判据

- **A：离线排序学习可行**：至少 2/3 seed 同时满足：测试 recorded-action Spearman≥0.60、MAE 优于常数基线、DAP1 首选动作等于测试集经验 target 首选动作、六阶段聚合 Spearman 中位数≥0.50。允许下一步设计一次短在线 warm-start smoke。
- **B：部分可学但不稳定**：至少一个 seed 达到全部条件，但少于 2/3；或多数 seed 明显改善回归误差但 DAP1/阶段排序未同时通过。只报告，不自动在线训练。
- **C：离线监督仍不能泛化**：所有 seed 均未达到全部条件，且多数 seed 不优于常数基线或排序相关不足。停止当前离线排序分支。
- **D：实现/划分失败**：动作覆盖、场景隔离、数值或复现检查失败。

不得根据结果改变 split、更新次数、阈值或 seed。

## 5. 输出

- 场景级 train/test split CSV；
- 阶段-动作覆盖检查 CSV/JSON；
- 三 seed 训练曲线及测试指标；
- checkpoint、Q/target 汇总和排序图 PNG/SVG；
- 结果 JSON 和中文记录。
