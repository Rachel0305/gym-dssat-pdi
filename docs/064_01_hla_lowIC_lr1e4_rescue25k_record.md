# 042_10 SYA lowIC binary-timing MaskablePPO 记录

## 结论边界

- 本任务继承 040_36 的 lowIC 自由时序 PPO、reward 和安全约束。
- 唯一核心改动：动作档位收缩为灌溉 [0,45] mm、施氮 [0,80] kg/ha。
- 目的不是最终优化剂量，而是先检验 PPO 能否学习自由决策时机。
- 训练步数：`25000`；checkpoint：`5000, 10000, 25000`。

## 固定配置

- lowIC 输入目录：`DSSAT_auto_validation/multisite_new_cultivar_inputs_013_lowIC_manual`
- 输入目录存在：`True`
- 灌溉档位：`[0.0, 15.0, 30.0, 45.0]`
- 施氮档位：`[0.0, 40.0, 80.0, 120.0]`
- 组合动作数：`16`
- reward：继承 040_36/040_28，不新增 reward 项。
- safety：继承 040_36，包括 7 天间隔、季节上限、DAP90 后禁氮、晚期灌溉保留。
