# 031_29 SY all-year DSSAT-auto fix and recorded-template transfer prompt

## Purpose

Extend the 031_28 SYA all-year baseline completion by:

1. repairing the all-year rendered template so DSSAT automatic irrigation/fertilization can run safely;
2. adding explicit recorded-farmer template-transfer scenarios based on the three available SY recorded years.

No PPO/DQN training is allowed in this task.

## Scientific boundary

`recorded_farmer_template_2012`, `recorded_farmer_template_2014`, and `recorded_farmer_template_2015` are not real recorded-farmer observations for the target year. They are counterfactual historical-management transfers, generated by mapping the source year's recorded management DAPs onto each target year. They must never be labelled simply as `recorded_farmer`.

## Planned generated scenarios

- `null`
- `dssat_auto`
- `official_extension_expert`
- `recorded_farmer_template_2012`
- `recorded_farmer_template_2014`
- `recorded_farmer_template_2015`

## DSSAT-auto repair

The 031_28 smoke showed that simply switching `IRRIG=A` and `FERTI=A` fails because the all-year rendered template has no `@ AUTOMATIC MANAGEMENT` block. 031_29 must add a valid automatic-management block before running `dssat_auto`, using the same parameter pattern as the original SY `CNSY1201.MZX`.

## Recorded-template transfer rule

Extract recorded irrigation and inorganic fertilizer rows from `DSSAT_auto_validation/multisite_new_cultivar_inputs_013/SY/CNSY1201.MZX` for treatments:

- 1 -> 2012
- 2 -> 2014
- 3 -> 2015

Convert source event dates to DAP relative to the source planting date, then apply the same relative DAPs to every target year. If source DAP is before the all-year RL episode can act, clamp to the earliest observed DAP and record this in the transfer manifest.
