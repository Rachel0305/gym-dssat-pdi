# 023_00 SY2014 阶段独立 Q-network ensemble 结构审计

## 1. 背景与唯一目的

022_20 在预注册配置下得到 0/3 seed 通过：DAP65 三个因果排序能够稳定学对，但 DAP110 八个因果排序只能保持 5–6 个。当前可以确认的是共享网络更新存在跨阶段耦合，尚不能把原因归结为网络容量或 DQN 理论失效。

本任务只回答一个结构问题：

> 将六个官方固定生育阶段分别交给参数完全独立的小型 Q 网络后，单独更新一个阶段是否能保证其他阶段的参数与 Q 值逐位不变？

本任务不是训练实验，不调用 DSSAT，不产生候选管理策略，也不宣称解决了 022_20。

## 2. 固定结构

- 阶段 DAP 固定为：`1, 30, 50, 65, 85, 110`；
- 每个阶段使用一套独立的 `25 -> 64 -> 64 -> 9` Q 网络；
- 六套网络不共享 trunk、head、参数或 optimizer state；
- DAP 必须精确匹配固定阶段，非法 DAP 立即报错；
- 动作合法性继续复用 `stage_based_dqn_core_022.valid_action_indices`；
- 结构初始化时，将 022_08 对应 seed 的单网络权重完整复制到六个阶段网络，确保拆分前后的初始预测完全一致。

## 3. 零训练审计

对 seed0/1/2 分别执行：

1. 检查六个阶段参数存储地址无重叠；
2. 检查拆分前后全部 288 条固定网格观测的 Q 值逐位一致；
3. 检查批量 dispatcher 输出与逐样本阶段网络输出逐位一致；
4. 对 DAP65 做一次仅用于单元测试、不保存的 Adam 更新：
   - DAP65 参数必须发生变化；
   - 其他五阶段参数哈希必须逐位不变；
   - 其他五阶段固定观测 Q 值必须逐位不变；
5. 对 DAP110 重复相同隔离检查；
6. 检查序列化/反序列化后所有参数与 Q 值逐位一致；
7. 输出训练/测试阶段样本覆盖表和每阶段参数量。

## 4. 预注册判据

单 seed 必须同时满足：

- `initial_q_max_abs_diff == 0`；
- `dispatch_q_max_abs_diff == 0`；
- DAP65 单元更新仅改变 DAP65；
- DAP110 单元更新仅改变 DAP110；
- 非目标阶段参数哈希和 Q 值全部不变；
- round-trip 参数和 Q 值逐位一致；
- 所有固定阶段在训练集和测试集中均有样本；
- 数值全部有限。

3/3 seed 通过才判 A，允许另立 023_01 固定离线训练；任一 seed 失败即判 C，停止并修复实现，不能作科学解释。

## 5. 严格边界

- DQN 正式训练步数：0；
- DSSAT 调用：0；
- 在线交互：0；
- 不修改 reward、IC、动作空间、阶段点、MC target、因果标签或 022_20 历史结果；
- 不扫描网络大小、学习率、loss 权重或训练步数；
- 不创建 023_01 训练结果；
- 不覆盖已有文件；
- 保存 prompt、实现、CSV、JSON、PNG/SVG 和中文实验记录。

## 6. 分支

- **A_structure_isolated**：3/3 seed 全部通过，允许编写 023_01 预注册训练任务；
- **C_implementation_failure**：任一结构隔离判据失败，停止，不进入训练。
