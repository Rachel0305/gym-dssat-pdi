# 本轮预报PPO结果分析

口径：固定100K主终点，8个训练seed，2014–2023十个验证年；各seed、年份等权。四站直接读取116主表，SY直接比较引用097已审计报告；五情景指标读取118合并表。全部保留，不筛seed、不筛年份。描述性比较，无新增模拟。

SY平均产量接近原PPO而节水，是较有价值的水分权衡结果；HL节水伴随减产；LC投入增加而平均产量未改善；YC增加水氮投入但仅小幅增产；FQ减水增氮，产量变化很小。未见五站一致的综合优势。

## 固定措施对照

- LC相对官方专家：增产447.15kg/ha（5.62%），平均少灌7.38mm、少施氮37kg/ha；但相对记录模板仅增产70.35kg/ha（0.84%），多灌61.62mm。优势依赖参照对象。
- YC相对记录模板与专家分别减产15.93%、18.26%；不能只以较低施氮和较高PFP_N称为全面改进。
- FQ相对记录模板仅增产12.38kg/ha，却多灌17.06mm、多施氮16.5kg/ha。自动灌溉+外部N情景在本轮为零施氮，产量7178.2kg/ha，PPO7214.08kg/ha；当前模拟输入条件下，额外投入的产量收益很小，不构成真实田间长期免氮结论。
- SY、HL相对专家分别减产3.09%、6.79%，同时显著减少水氮；应表达为投入—产量权衡。

## 稳定性与策略行为

8seed的十年平均产量范围：SY8838.5–10210.3，HL5296.9–6833.0，LC5652.1–9195.4，YC3552.3–8202.5，FQ7118.4–7374.7kg/ha。LC、YC的不稳定尤其明显。

LC seed2十年均N=0、I=165mm，平均产量5652.1kg/ha；YC seed2十年I=45、N=0，平均3552.3；YC seed3十年I=45、N=40，平均5348.3。高产策略也存在：LC六个seed平均产量约8799–9195；YC seed0、1、7均约8202。但这些端点同时保留，不能用最好seed代表整个方法。

FQ seed0和4的十年总量均固定I=45、N=120；seed5固定I=45、N=240；seed6固定I=45、N=40。相近产量对应明显不同投入。这说明不同训练终点产生不同资源配置；总量固定并不能单独证明完全忽略预报，动作时机和对预报的响应仍需独立诊断。

HL十年站点平均产量均低于原PPO；LC只有3年、YC4年、FQ7年高于原PPO，均为描述性结果，不是独立样本显著性检验。

## 解释边界和下一步

1. 五情景中的第五组是预报PPO；赢过固定模板并不等于证明预报有增益。原无预报PPO比较是另一条证据。
2. 输入维数、初始化随机流及历史训练抽样并非严格受控；同编号seed不是严格随机配对，以上差异不可直接归因于预报信息。验证年也不是额外80个独立训练重复。
3. 这是完美七日摘要，尚不能推广为真实预报条件收益。
4. PFP_N在N=0时缺失。四站预报/原PPO有效记录数：HL74/80、LC70/80、YC70/80、FQ80/70。因此不将不同有效样本的PFP_N均值百分比当作单独的氮效率证据，也不把PFP_N写成NUE。
5. 优先用已有模型做保持合法动作掩码的预报置换/替换诊断，并查低产seed的动作概率、熵、资源耗尽和优化曲线。确认信息响应及退化原因后，再决定是否调整或重训。本次不新增模拟、不自动扩展训练，不删除不利seed，不改变冻结对照。
