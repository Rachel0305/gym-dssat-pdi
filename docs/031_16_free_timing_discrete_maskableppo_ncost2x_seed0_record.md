## Interpretation boundary

This is a single-seed algorithmic smoke. It can indicate whether discrete MaskablePPO is more promising than the DQN/continuous-PPO failures on SYA2014, but it is not a cross-seed or cross-year claim.

## Result interpretation

Branch: mixed / partial positive, not successful.

The discrete MaskablePPO change did alter the learned resource behavior: the final deterministic policy used N200 rather than saturating the N250 cap. This is better than the literature-style DQN ncost2x runs on nitrogen economy and PFP_N.

However, the policy did not learn good free-timing management. It applied all N200 by DAP9 (DAP2 N120 and DAP9 N80), produced 21 days with NSTRES > 0.05, and reached only 10132.14 kg/ha grain yield. This is far below the known staged N200 counterfactual from 031_12 (10882.18 kg/ha with I72/N200) and below the uniform/expert-window budget reference from 031_05 (10908.60 kg/ha with I160/N250).

Therefore 031_16 should not be expanded to all sites/years. The result supports one narrower conclusion: action masking plus a discrete PPO policy can reduce nitrogen cap saturation, but current PPO value/policy learning still fails to discover the high-yield timing pattern under the free daily action setting.

Recommended next diagnostic: keep the same action grid, masks, caps, seed, and training length, and change only reward numerical scaling (for example divide the reward by 1000 or use reward normalization) to test whether PPO value learning is blocked by reward/value scale rather than by the action representation itself. This is a training-stability test, not a change in management preference ordering.
