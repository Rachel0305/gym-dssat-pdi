# 022_01 SY2014 官方固定阶段动作空间确定性可行性搜索

## 1. 目的

在不训练DQN的前提下，验证022_00冻结的官方固定DAP动作空间中，是否客观存在同时达到产量和水氮利用效率目标的合法方案。若不存在，不允许进入022_02训练，也不得事后移动阶段点或放宽门槛。

## 2. 冻结输入

- SY2014、IC=2、PDI/DSSAT 4.8.0；
- 环境输入复用021_14/021_18已经验证的同一份 `dqn_env_args.json`；
- 阶段点固定为DAP1/30/50/65/85/110，来源为官方推文表1东北春玉米区，经018_02/018_03固定DAP映射；
- 动作档位保持I∈{0,15,30}、N∈{0,50,100}；
- I≤120、N≤300；DAP90后N=0；
- 不训练、不改reward、不改IC、不改DSSAT输入。

## 3. 判据来源

### 3.1 主科学判据

直接沿用021_18原始预注册定义，而不是事后拼接旧结果：

1. HWAM≥11077 kg/ha，即不低于同输入official expert与auto中的较高者；
2. WP_ET不低于两套基准中的较高者；
3. N>0时PFP_N≥official expert的36.923 kg grain/kg N；
4. I≤120、N≤300；
5. DAP90后N=0。

### 3.2 严格附加等级

在主科学判据之外，另报：I≤90、N≤250。

该等级不是021_18原始门槛；它后来用于021_20示范学习smoke，并受到021_18已找到I75/N200候选的启发。它只用于给候选分级，不得冒充独立于历史结果的原始判据。

## 4. 输入链smoke

先用021_18已验证的oracle时序做一次独立回放：DAP22/29/42/56/79，I75/N200，预期HWAM=11205±2 kg/ha且Summary.OUT总量I75/N200。该smoke只核验输入与执行链，不进入固定阶段候选排名。

smoke失败立即停止。

## 6. 输出与停止规则

输出候选summary、主判据成功表、严格等级成功表、动作计划表、PNG/SVG和中文记录。

- 至少一个主科学判据候选通过：允许另立022_02训练预注册；
- 主判据无人通过：停止，不训练，不移动阶段点，不临时放宽任何阈值；
- 严格等级无人通过但主判据有人通过：如实标为“科学目标可行、严格资源目标未证实”，仍可由后续022_02决定是否训练，但不能宣称I90/N250上界存在；
- 任何输入、执行总量、Summary匹配或smoke异常：failed，停止解释。
