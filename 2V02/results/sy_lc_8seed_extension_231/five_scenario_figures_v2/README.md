# SY and LC 100K PPO five-scenario figure packages

Each site has seven new seed folders (`seed_01`–`seed_07`). Every folder holds
12 figures, four tables, ten PPO replay snapshots, and an `audit.json`.
Frozen seed0 remains in its original 046_06 (SY) or 053_03 (LC) directory.

Open `SY/eight_seed_ten_year_means.csv` or `LC/eight_seed_ten_year_means.csv`
for all eight seeds together. The corresponding `eight_seed_annual_ppo_metrics.csv`
contains every validation year. No seed or year is omitted for weak performance.

Experiment record: `docs/232_sy_lc_8seed_five_scenario_figure_record.md`.
