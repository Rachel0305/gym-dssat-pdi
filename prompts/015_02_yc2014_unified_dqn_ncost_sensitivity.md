# 015_02 YC2014 统一 DQN 奖励函数氮成本敏感性诊断

## 目的

在进入多站点、长步长正式训练前，先确认统一经济奖励函数中的氮肥成本系数是否过强，导致 DQN 在 YC2014 中学成“只灌水、不施氮”的策略。

015_01 的 50K seed0 结果显示：

- 统一 9 动作 DQN 使用 90 mm 灌溉；
- 施氮量为 0 kg/ha；
- 产量约 8056 kg/ha；
- 比 null 有提升，但低于此前探索性 DQN / recorded expert 的高产结果。

因此本轮不扩大站点、不跑 seed1、不直接继续 50K，而是先做低成本 reward 诊断。

## 固定不变的设置

- 站点年份：YC2014
- 算法：DQN
- seed：0
- 训练步数：5000，用于诊断，不作为正式结果
- 动作空间：9 个离散动作
  - I ∈ {0, 15, 30} mm
  - N ∈ {0, 50, 100} kg/ha
- 预算约束：
  - 季节灌溉量 I ≤ 120 mm
  - 季节施氮量 N ≤ 300 kg/ha
- 最小操作间隔：7 days
- 管理模式：IRRIG=L, FERTI=L，保留原管理表和指针
- 水成本：WATER_COST = 1.0

## 本轮唯一扫描变量

扫描全局氮成本：

```text
N_COST = 0.5, 1.0, 2.0, 3.0, 5.0
```

奖励函数：

```text
R_t = max(0, GRNWT_t - GRNWT_{t-1}) - 1.0 * I_t - N_COST * N_t
```

注意：本轮不是为 YC2014 单独调参，而是判断哪个氮成本区间可能作为所有站点统一使用的候选。

## 输出要求

保存到：

```text
DSSAT_auto_validation/yc2014_unified_dqn_ncost_sensitivity_015_02/
```

需要输出：

- 每个 N_COST 的日值 CSV；
- 汇总 CSV；
- 对比图；
- 中文实验记录 MD；
- 记录每个候选下的：
  - 灌溉总量
  - 施氮总量
  - 最终产量
  - 最终生物量
  - 最大水分胁迫
  - 最大氮胁迫
  - 累积 reward

## 判断规则

如果 N_COST=5 时完全不施氮，而较低 N_COST 能恢复合理施氮并提高产量，说明 015_01 的失败主要来自氮成本过强。

如果所有 N_COST 都不施氮，则说明问题不只是成本系数，可能包括：

- 阶段 ΔGRNWT 奖励不能体现氮肥延迟收益；
- DQN 在该动作空间下仍难以学习施氮收益；
- 需要改为终季收益、相对 no-op 收益、或分阶段 shaping。

如果很低 N_COST 导致氮肥打满且产量并不提高，则说明需要在统一奖励函数中重新设计氮收益/成本表达，而不是简单降低氮成本。
