# 016_06 FQ 施氮响应弱原因诊断 prompt

## 目标

在不训练强化学习模型的前提下，解释为什么 FQ2008 / FQ2016 在 `016_05` 的确定性扫描里表现出明显灌溉响应、但几乎没有施氮响应。

## 已知现象

- `016_05` 中：
  - `FQ2008` 最优组合为 `I60_N0_critical`，`GWAD=8187`
  - `FQ2016` 最优组合为 `I60_N0_critical`，`GWAD=8012`
- 同时加到 `N150` / `N300` 后，产量没有提升，甚至略降。
- FQ2007/2008 的旧失败已确认是 FileX 日期问题，不是年份不可用。

## 诊断思路

1. 固定灌溉为 `I60 critical`，只扫描氮总量：
   - `N = 0, 25, 50, 75, 100, 150, 200, 250, 300`
2. 年份：
   - `FQ2008`
   - `FQ2016`
3. 输出：
   - `GWAD`
   - `CWAD`
   - 最大 `SWFAC`
   - 最大 `NSTRES`
   - 最终 `DAP`
4. 同时记录：
   - 当前 FQ 初始条件中的 `SNH4/SNO3`
   - 便于判断是“本来就不缺氮”，还是“氮不是主限制因子”

## 判定目标

如果 `N` 从 0 提高到 300 时：

- `NSTRES` 明显下降，但 `GWAD` 不升：
  - 说明氮胁迫存在，但不是主导产量的限制因子。
- `NSTRES` 和 `GWAD` 都几乎不变：
  - 说明当前年份/时机下系统几乎不缺氮。
- 小量氮有用、大量氮无用：
  - 说明存在更窄的可达氮平台，可为后续 RL 约束设计提供依据。

## 原则

1. 不开训练。
2. 不覆盖旧结果。
3. 结果写入独立目录。
4. 记录实验结论到中文 MD。
