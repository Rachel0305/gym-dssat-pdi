# 三路线结果：论文结论修订稿

采用共同FQ2018质量控制版本；每站每路线8个独立训练模型，每模型评价2014—2023十年。结果是描述性路线比较，不声称完整单因素合同认证。

1. **收益类型具有站点依赖性。**120策略中20个达到十年均产增加≥1%，46个满足产量不低于参照95%的节资条件，交集2个、并集64个。新增预报40策略贡献7个增产、15个节资、并集21个。该收益阈值以专家或模板中较高产的真实策略为参照，不等于预报优于原PPO。

2. **较好种子不代表典型表现。**主图保留15组全部8个种子的十年均值；LC、YC存在明显低产种子，不能只选最好seed支持方法优势。种子不确定性与年度风险分开统计；1200年度不能当1200个独立训练重复。

3. **水氮与操作限制补充产量评价。**逐层筛选77→47→29，最后29个中12个带固定完整措施序列标签。固定序列不删除，29也不是部署推荐名单。按路线为原80策略51→31→19，新增40为26→16→10；原80实际上含原PPO和增强PPO两个路线，不能称为单一基线。

4. **天气扩展尚无稳定全面优势的证据。**增强减原PPO15项、预报减原PPO15项Welch 95%区间全部跨0，不能推出等效或无效。以下为三指标点估计，需连同区间和各seed展示：

|站点|增强：产量/灌溉/氮变化|预报：产量/灌溉/氮变化|
|---|---|---|
|SY|-481.6 / -45.2 / -9.5|-33.9 / -31.3 / -2.0|
|HL|-324.0 / -28.9 / -11.5|-297.3 / -29.1 / -1.0|
|LC|-329.0 / -9.2 / +46.5|-46.6 / +14.1 / +43.0|
|YC|-247.2 / -11.4 / +11.0|+127.4 / +20.6 / +64.5|
|FQ|+60.7 / +0.6 / +8.0|+30.5 / -18.4 / +23.5|

单位分别为kg/ha、mm、kg N/ha。SY、HL预报路线灌溉点估计降低但产量也降低；LC预报平均产量接近原PPO却追加水氮；YC产量点估计提高同时增加水氮；FQ预报平均产量接近原PPO、灌溉降低、氮增加。都不支持天气预报普遍提高产量并同时节水节氮。

增强确有逐回合训练使用证据，但不由此证明泛化改善；理想预报是否真正用于决策仍须专门诊断。已有SY seed0置换仅支持指定样本内响应极弱，不能推广全部40模型。无需先加训增强+预报来追求正结果，下一阶段转向已有模型的预报响应分析和论文组织，停止扩大天气审查。

科学限制：共同FQ2018采用启发式TMIN符号修正，非独立观测真值；门槛为事后探索性；Welch区间未经多重比较校正；未进行等效性检验。PFP_N零氮为未定义，不能称NUE或长期可持续性。
