# 022_18 SY2014 保守参数路径可行性审计

## 1. 目的

在设计新的锚定/蒸馏权重前，先利用022_15已经存在的update0和update500 checkpoint，检查两者之间的线性参数路径上是否存在同时满足以下条件的模型：

1. 三个受控DAP65状态均有`Q(a1)>Q(a7)`；
2. 022_17确认的8个非别名DAP110状态均选择因果回报更高的action0。

这一步只判断“保守路径上是否存在兼顾局部修正与已证实保护目标的区域”，不训练、不保存插值模型。

## 2. 固定方法

对seed0/1/2分别定义：

```text
theta(alpha) = (1-alpha)*theta_update0 + alpha*theta_update500
alpha = 0.000, 0.001, ..., 1.000
```

网格分辨率预先固定为0.001，不根据结果细化或扩大到路径外。

同时记录原MC训练loss、DAP1和DAP85在11个未污染测试状态上相对update0的argmax变化，仅作guardrail描述；不把未经因果验证的所有状态强制冻结。

## 3. 分支

- A：至少2/3 seed存在满足两项因果条件的alpha；
- B：仅1/3存在；
- C：0/3存在；
- D：实现或数值失败。

存在可行alpha不等于在线训练已成功，也不允许事后挑该插值模型直接汇报；它只支持下一步设计保守更新/信任域机制。不存在则说明当前0→500训练方向本身无法同时满足两类目标，不应继续沿该路径调早停点。

## 4. 输出

- 3003个seed×alpha审计点；
- 每seed可行区间、首个DAP65纠正点和首个DAP110保护失败点；
- CSV、JSON、PNG/SVG和中文记录；
- DQN训练0步、DSSAT调用0次、无新checkpoint。
