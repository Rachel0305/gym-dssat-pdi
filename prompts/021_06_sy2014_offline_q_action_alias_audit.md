# 021_06 SY2014 离线 Q 排序与动作混叠审计

## 背景

021_05 已确认五站点旧分段训练协议使探索率过早降至 0.05。修复后，SY2014 seed0 的高产策略维持到 15K，但 20K 起施氮从 300 kg/ha 降为 0，而灌溉仍为 120 mm。现有整体 Q 最大值不足以区分 Q 排序漂移与 wrapper 动作裁剪/混叠。

## 目标

只使用 021_05 已有 5K、10K、15K、20K、25K checkpoint，诊断：

1. 在同一观测状态下，9 个离散动作的 online Q 和 target Q 排序如何变化；
2. 15K 到 20K 是否发生高氮动作与零氮动作的排序反转；
3. 预算、7 日共享操作间隔和 DAP1–120 窗口是否把多个请求动作裁剪成相同执行动作；
4. 排序反转与动作混叠是否单独或共同出现。

## 严格边界

- 不训练；
- 不修改 reward、IC、DSSAT 输入、动作空间、预算或超参数；
- 不覆盖 021_05 输出；
- 允许对已有 checkpoint 做确定性前向评估，以捕获未保存在旧 CSV 中的原始观测和 wrapper 状态；
- 若字段不能可靠重建，必须标记为不可判定，不得推测补齐。

## 固定状态面板

分别以 15K 和 20K checkpoint 的确定性轨迹作为状态来源，优先选择真实出现的以下 pre-step DAP：

- DAP 1：预算完整；
- DAP 8、15、22：预算逐步使用；
- DAP 29、36：接近或达到季节上限；
- DAP 50、80：预算耗尽后的季中状态；
- DAP 121：操作窗口结束后。

若某个 DAP 不存在，选择最近的实际 DAP并记录偏差。每个捕获状态必须记录来源 checkpoint、实际 DAP、累计灌溉、累计施氮、剩余预算、上次操作 DAP 和是否满足 7 日操作间隔。

## Q 值审计

对每个固定状态，将完全相同的观测向量输入 5K/10K/15K/20K/25K 的 online Q 和 target Q 网络，输出动作0–8的完整数值和排名。

动作分组：

- 同灌溉 I0：N0/N50/N100（动作 0/3/6）；
- 同灌溉 I15：N0/N50/N100（动作 1/4/7）；
- 同灌溉 I30：N0/N50/N100（动作 2/5/8）。

定义每组氮偏好边际：

`M = max(Q(N50), Q(N100)) - Q(N0)`。

- `M > 0`：该状态下网络偏好至少一个高氮动作；
- `M < 0`：该状态下网络偏好零氮动作；
- 15K 与 20K 符号相反，记为 rank flip；
- 若两个 checkpoint 的 `|M|` 均不小于各自 9 动作 Q 标准差的 0.25 倍，另记为 robust rank flip。

0.25 倍标准差只是预注册的描述性阈值，不是文献阈值，也不能单独证明因果。

## 动作混叠审计

在每个固定状态下，把9个请求动作分别通过与正式 wrapper 相同的规则投影为实际动作，记录：

- 请求动作索引及 I/N；
- 实际执行 I/N；
- 裁剪原因：DAP<1、7日间隔、窗口外、灌溉预算、氮预算或无裁剪；
- 9个请求动作最终对应多少个唯一执行动作；
- 每个执行动作对应哪些请求动作。

必须同时指出：当前 DQN 观测配置不包含 `used_irrigation`、`used_nitrogen` 或 `last_operation_dap`。若核查属实，应记录其造成的部分可观测性风险，但不能在本任务中修改观测空间。

## 判定纪律

- 只有固定状态下的相对 Q 排名变化才能称为排序反转；
- online Q 高于 target Q 不能单独称为过估计根因；
- 请求动作被裁剪为同一执行动作，只能说明动作混叠存在，不能单独证明它导致坍缩；
- 若两类证据同时存在，结论写为“共同候选机制”，不写成已确认因果。
