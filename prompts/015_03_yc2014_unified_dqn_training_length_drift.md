# 015_03 YC2014 统一 DQN 训练步长漂移诊断

## 背景

015_01 中，YC2014 统一 DQN 在 50K seed0 下学成：

- 灌溉 90 mm；
- 施氮 0 kg/ha；
- 产量约 8056 kg/ha。

但 015_02 中，完全相同的统一奖励框架、相同 `N_COST=5.0`，在 5K seed0 下学成：

- 灌溉 120 mm；
- 施氮 250 kg/ha；
- 产量约 9418 kg/ha。

这说明问题不太像简单的氮成本过强，而可能是 DQN 长训练后策略漂移、Q 值偏移、探索衰减或回放缓冲区导致的训练稳定性问题。

## 目的

在不扩大站点、不跑多 seed 的前提下，用低成本补点判断：

```text
5K -> 10K -> 20K -> 50K
```

过程中策略是否从高产水氮操作逐渐漂移到少氮/不施氮。

## 固定设置

- 站点年份：YC2014
- 算法：DQN
- seed：0
- 奖励函数：

```text
R_t = max(0, GRNWT_t - GRNWT_{t-1}) - 1.0 * I_t - 5.0 * N_t
```

- 动作空间：9 个离散动作
  - I ∈ {0, 15, 30} mm
  - N ∈ {0, 50, 100} kg/ha
- 预算：
  - I ≤ 120 mm
  - N ≤ 300 kg/ha
- 最小操作间隔：7 days
- 管理模式：IRRIG=L, FERTI=L

## 计算策略

为了节省算力：

- 复用 015_02 中已有的 5K / N_COST=5 结果；
- 复用 015_01 中已有的 50K / N_COST=5 结果；
- 本轮只新跑 10K 和 20K。

## 输出

保存到：

```text
DSSAT_auto_validation/yc2014_unified_dqn_training_length_drift_015_03/
```

输出：

- 10K、20K 日值 CSV；
- 汇总 CSV，包含 5K、10K、20K、50K；
- 训练步长对比图；
- 中文实验记录 MD。

## 判断规则

如果 5K 高产施氮、10K/20K/50K 逐渐减少施氮或产量下降，则说明统一 DQN 框架存在长训练策略漂移。

如果 10K/20K/50K 都保持 I120/N250 左右的高产行为，则 015_01 的 50K 不施氮可能是脚本或配置不一致，需要回查 015_01 与 015_02 的配置差异。

如果 10K/20K 结果剧烈跳变，则说明该 DQN 设置 seed0 下训练不稳定，下一步应优先检查 DQN 训练机制，而不是扩站点。
