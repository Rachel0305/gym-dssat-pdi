# 024_00 SY2014 监督阶段策略标签可识别性审计记录

## 1. 目的

在停止 023 阶段独立 Q 回归路线后，本任务检查是否可以直接使用现有数据训练一套覆盖六阶段的监督排序/阶段策略。该方法明确不是 DQN/Q 回归的延续。

本任务只审计标签来源、场景隔离和逐阶段动作覆盖；监督训练 0 步、DSSAT 调用 0 次。

## 2. 动作空间边界

DSSAT 环境在 DAP110 原生允许 `{0,1,2}`，但智能体从 022_05 起在训练、探索和评估中一致使用数据支持子集 `{0,1}`。024 路线延续智能体支持子集，不修改环境原生定义，也不声称覆盖 action2。

## 3. 标签来源分级

- 受控因果标签：DAP65 三个状态、DAP110 八个非别名状态；
- 严格成功模仿标签：022_01 的 18 个严格成功完整方案；
- 历史 MC 关联：48 个不同管理历史方案产生的回报，不作为同状态动作排序真值；
- 未知：没有严格成功模仿标签，也没有受控因果标签。

为了防止泄漏，11 个受控因果场景全部留作独立测试。它们与严格成功方案有 5 个重叠，因此排除后只剩 13 个严格成功方案可用于模仿训练/验证。

## 4. 总体结果

判定为：**C_labels_insufficient**。

| 指标 | 数量 |
|---|---:|
| 行为支持的阶段-动作 | 23 |
| 至少有2条严格模仿标签 | 13 |
| 单例、无法拆分训练/验证 | 3 |
| 完全缺少可靠标签 | 5 |
| 仅有独立因果测试证据 | 2 |
| 剩余严格成功模仿场景 | 13 |

六阶段都至少存在一个可训练动作，但这不足以训练覆盖全部行为支持动作的策略。

## 5. 逐动作缺口

### 5.1 完全未知

- DAP1：action1、action4；
- DAP30：action5、action8；
- DAP85：action2。

### 5.2 单例

- DAP50：action5；
- DAP65：action1、action8。

这些动作在排除因果测试场景后的严格成功方案中仅出现1次，不能同时进入训练和验证。

### 5.3 仅因果测试

- DAP65：action7；
- DAP110：action1。

它们具有受控比较证据，但这些状态已预注册为独立因果测试，不能同时作为训练标签使用。

## 6. 结论

现有数据能够支持以下事实：

- 18 个严格成功管理方案客观存在；
- DAP65 和 DAP110 的11个状态拥有受控因果比较；
- 某些阶段动作具有可用于模仿的重复严格成功标签。

但现有数据不能支持：

- 一套覆盖全部23个行为支持阶段-动作的监督策略；
- 将不同管理历史下的 MC 回报解释成同状态动作排序；
- 使用当前13个模仿场景训练模型后宣称其对未覆盖动作具有可靠判断；
- 进入024_01三seed监督训练。

## 7. 硬停止与下一步选择

`next_step_allowed=false`，不启动024_01，也不现场缩小动作空间、合并动作类别或降低最小支持门槛。

若继续追求可写入论文的成功策略，下一步必须在两条新方向中重新选择并预注册：

1. 使用受控 DSSAT 对照有计划地补充缺失动作标签，再训练监督策略；
2. 放弃从小样本学习完整策略，直接将已经验证存在的确定性管理搜索/优化作为正式方法路线。

本任务不替用户或导师决定上述方法方向。
