# 053 HLA WGEN 天气增强与八种子训练恢复

## 目标

以 FQA 051–052 的已冻结流程为参照，在 HLA 单站建立可复现的 WGEN 训练天气，并在天气与运行门禁通过后顺序执行 PPO seed 0–7 的 100K 训练、2014–2023 验证和同结构图表。保留每个 episode 实际使用的随机天气、25K/50K/75K/100K checkpoint、最终模型、Summary.OUT、失败日志及机器可读审计。

## 冻结边界

- 不修改历史 HL/FQ/YC 训练结果、原始 D222、原始 WTH、FileX、奖励或 PPO 合同。
- HLA 使用原有 lowIC/HL 输入，训练年份 2004–2013，验证年份 2014–2023；与旧 HL 100K 八种子结果比较前逐项核对配置。
- 用户已决定保留权威 D222 原值，包括高降雨量；逐日补源与 111 天缺口仍按输入清单明确列出，不将参考格点值称为站点观测。
- 029 的五份 CLI 属独立敏感性轨道；在用户选定正式训练输入前，不把其中一份暗中当作唯一正式来源。
- 032–037 的 FIELD 坐标转写异常保留为已知运行限制。训练前必须给出实际 runtime 天气与坐标证据，说明是否影响物理过程及与历史基线的可比性；不得静默忽略警告。

## 执行门禁

1. 核对 029/024 输入、CLI、哈希和 2004–2013 日期；五轨道各做限量天气候选，保存实际 WGEN seed、逐日 SRAD/TMAX/TMIN/RAIN 和运行时证据。
2. 做结构、物理、月/年雨量、极端值及跨 seed 多样性检查。候选不通过则停止，不筛掉不利天气后继续训练。
3. 按 FQA 的单进程模式做小规模 PPO smoke，核对 HLA lowIC 输入、WTHER=W、CNHL.CLI、动作传递、实际天气逐日归档和 RSS；单进程顺序运行以防 OOM。
4. 只有来源选择、天气 QA、坐标影响/可比性和 smoke 均有可审计结论，才执行每 seed 100K。每个 seed 先完整归档再启动下一个；失败保留现场，不覆盖旧产物。
5. 精确 100K checkpoint 在历史 2014–2023 天气下验证，对照同输入合同的冻结基线；报告产量、灌溉、施氮、WP_ET、PFP_N、seed 分散及小灌频次。最后生成图表、SHA-256 清单、实验记录与冻结标签候选。
