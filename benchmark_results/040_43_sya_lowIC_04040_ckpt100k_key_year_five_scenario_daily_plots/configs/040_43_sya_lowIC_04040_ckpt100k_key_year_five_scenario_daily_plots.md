# 040_43 SYA lowIC 040_40 checkpoint100K 关键年份五情景日过程图

## 背景

040_42 显示 040_40 checkpoint100K 在 SYA lowIC 2014–2023 验证年中：

- 至少一项指标超过四情景最高：10/10 年；
- 产量超过四情景最高：5/10 年；
- WP_ET 超过四情景最高：3/10 年；
- PFP_N 超过四情景最高：10/10 年。

040_40 相比 040_36 更保产，但灌溉/施氮投入也提高。因此需要人工检查其关键年份的措施过程是否合理。

## 本任务目的

不训练、不调参、不改 checkpoint。只绘制 040_40 checkpoint100K 的关键年份五情景日过程图，用于解释：

1. 2017 年为什么仍然低于 expert；
2. 2022 年为什么 WP_ET 明显低于四情景最高；
3. 2015、2018、2023 这类成功年份的措施是否合理；
4. 是否出现“指标好但措施不合理”的情况。

## 年份选择

预注册固定绘制：

- 2014：产量仍低于 expert，且有水分胁迫；
- 2017：主要失败年；
- 2021：WP_ET 与 PFP_N 均有优势但产量略低；
- 2022：PFP_N 胜出但 WP_ET 明显不足；
- 2023：产量和 PFP_N 胜出。

## 输入

- PPO 040_40 checkpoint100K 验证 daily/summary：
  - `benchmark_results/040_40_sya_lowIC_ppo_yield_guardrail_v3/evaluation/040_40_checkpoint_validation_summary.csv`

## 输出

- 5 张五情景日过程图；
- 合并日值表；
- 终值汇总表；
- PPO 管理事件表；

## 判读边界
