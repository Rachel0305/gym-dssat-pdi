# 010_12 HLA 初始土壤水氮基线小扫描

## 背景

HLA 2004-2023 的 IC=1 null 结果显示，直接把 2004 年初始土壤水氮剖面平移到所有年份后，多数年份在无灌溉、无施肥条件下也能达到 5-8 t/ha 籽粒产量。这说明该统一初始剖面对多年 null 情景的生产潜力影响很强，不能不加检验地替代 IC=0 主实验。

但 IC=0 null 又表现出过低产量和异常胁迫结构。因此需要寻找一个更适合作为管理优化基线的初始条件：既不能让 null 过高，也不能让作物几乎无法正常生长。

## 已有依据

项目已有 `docs/soil_water_and_nitrogen_initialization_summary.md`，其中初始土壤水分采用：

```text
SH2O = SLLL + 0.55 * (SDUL - SLLL)
```

该公式把初始水分设置在植物可利用水范围的中等偏干位置。HLA 的矿质氮剖面被标注为 record-based and preserved：

```text
@C  ICBL  SH2O  SNH4  SNO3
 1    20  0.26  22.7  10.1
 1    40  0.26  10.8  11.3
 1    60  0.26  15.1  12.5
 1    90  0.25   8.2   8.1
```

因此本轮扫描不否定这组 record-based 剖面本身，而是检验：把 2004 年这组剖面作为所有年份的统一初始条件时，是否需要对矿质氮/水分做可解释的缩放，才能形成合理的 null 基线。

## 目标

寻找一个候选初始条件，用于后续 HLA 管理优化情景的基线测试。理想候选应满足：

1. null 情景不应高到 5-8 t/ha，否则无管理已接近高产，管理空间不足；
2. null 情景也不应长期 0-500 kg/ha 且作物几乎不生长，否则初始条件过差或过程异常；
3. HLA 2004、2012 这类异常年份应继续被识别为异常，而不是被初始条件完全抹平；
4. WSPD/NSTD 应能反映水氮限制，而不是全程近 0 或全程极端；
5. 选择应有农学解释：水分优先锚定在 `SLLL + fraction × (SDUL - SLLL)`，氮素优先解释为 record-based 剖面的保守缩放。

## 扫描设计

为了节省算力，本轮先跑 HLA 2004 和 HLA 2012 两个关键异常年份。第一轮完成后发现异常年份不足以判断正常年份的 null 产量是否仍然过高，因此追加 HLA 2009 作为代表性高产/正常响应年份。

### 为什么选择 2004、2009、2012

本轮不是随机抽年份，也不是为了挑 PPO 好看的年份，而是为了用最少年份覆盖三类诊断场景：

1. **2004：当前主实验年份，也是异常低产/零籽粒机制重点年。**
   - 之前大量 PPO、四情景图、IC=0/IC=1 对比都围绕 HLA 2004 展开；
   - IC=1 下 2004 出现“生物量明显增加但籽粒仍为 0”的现象；
   - 因此 2004 必须纳入，用来判断新 IC 是否会改变主实验结论。

2. **2012：另一个异常低产年份，用来检验候选 IC 是否会把异常年份强行救成正常年。**
   - IC=0 与 IC=1 下 2012 籽粒都为 0；
   - 如果某个 IC 组合把 2012 直接变成高产，说明它可能过强，抹平了真实年份差异；
   - 因此 2012 是“异常年鲁棒性检查”。

3. **2009：代表性高产/正常响应年份，用来判断 null 是否仍然过高。**
   - 只看 2004/2012 会有偏差，因为异常年份本身很难形成籽粒；
   - 原 IC=1 下，2009 null 籽粒产量约 8 t/ha，是“初始剖面过强”的典型表现；
   - 因此追加 2009，用来测试候选 IC 是否能把正常年份 null 降到合理区间，同时仍允许作物正常形成籽粒。

这三个年份的组合逻辑是：

```text
2004 = 主实验年份 / 异常机制重点
2012 = 异常年份鲁棒性检查
2009 = 正常或高响应年份的 null 过高检查
```

如果一个 IC 候选在 2009 能降低过高 null，在 2004/2012 又不把异常年强行救成高产，那么它才值得进入下一轮多年验证。

固定项：

- 站点：HLA
- 作物：maize
- 品种、土壤、种植日期、天气：沿用现有 HLA 输入
- 管理：null，无灌溉、无施肥
- 模型：PDI/gym DSSAT 4.8.0
- 不训练 PPO

变量：

- 水分 fraction：`0.35, 0.45, 0.55, 0.65`
  - 公式：`SH2O = SLLL + fraction × (SDUL - SLLL)`
  - `0.55` 是已有文档采用的中等偏干设定；
  - `0.35, 0.45` 测试更干初始条件；
  - `0.65` 测试稍湿条件。
- 矿质氮缩放：`0.25, 0.50, 0.75, 1.00`
  - 基于 HLA record-based SNH4/SNO3 剖面按比例缩放；
  - `1.00` 为原始 record-based 剖面；
- `0.25-0.75` 表示在“多年统一初始条件”场景下采用保守矿质氮初始供给。

### 为什么选择这些水分和氮组合

本轮实际是一个 **4 × 4 的小型因子扫描**，不是九组；每个年份有 16 组水氮初始条件，三个年份共 48 次模拟。

水分 fraction 的选择依据：

- `0.55` 是已有项目文档采用的设定，有明确公式和依据；
- `0.35`、`0.45` 是比 0.55 更干的情景，用来检查是否需要降低初始水分；
- `0.65` 是稍湿情景，用来检查水分变湿是否显著推高 null；
- 四个点围绕 0.55 展开，目的是判断“初始水分是不是主导因素”，而不是精细校准水分。

矿质氮 scale 的选择依据：

- `1.00` 是原始 HLA 2004 record-based 矿质氮剖面；
- `0.75` 是轻度保守缩放；
- `0.50` 是中度保守缩放；
- `0.25` 是强保守缩放；
- 四个点用于判断“初始矿质氮是不是导致 null 过高的主导因素”。

选择这个粗网格的原因：

1. 先做低成本诊断，不追求一步找到最终最优 IC；
2. 每个变量只取 4 个代表点，避免算力膨胀；
3. 水分和氮分开成因子组合，可以判断是水主导还是氮主导；
4. 如果粗网格已经显示某个方向明显，比如 `N_scale=0.25` 与 `0.50` 差异巨大，再决定是否加密扫描。

组合数：

- 第一轮：4 × 4 × 2 年 = 32 次 DSSAT 前向模拟。
- 追加正常年份后：4 × 4 × 3 年 = 48 次 DSSAT 前向模拟。

## 评价指标

每个组合记录：

- 最终籽粒产量 `GWAD/HWAM`
- 最终地上生物量 `CWAD/CWAM`
- 最终 DAP
- `max_wspd`, `mean_wspd`
- `max_nstd`, `mean_nstd`
- 是否成熟/是否形成籽粒

## 候选筛选规则

优先保留满足以下条件的组合：

1. **正常年份不能 null 过高**：以 2009 为代表，null 不应接近 7-8 t/ha，否则无管理已经高产，施肥/灌溉/PPO 的管理空间不足；
2. **异常年份不能被抹平**：2004、2012 不应被某个 IC 组合直接抬成正常高产，否则该 IC 可能过强；
3. **作物仍需能生长**：至少在正常年份能形成籽粒，在异常年份也应有一定生物量响应，而不是完全死掉；
4. **胁迫指标应保留响应空间**：WSPD/NSTD 不应全程无变化，也不应全程极端饱和；
5. **解释优先于拟合**：优先选择有项目已有依据的水分设定，如 `water_fraction=0.55`；氮缩放若需要降低，必须解释为“统一多年初始剖面的保守缩放”，而不是随意调参；
6. **先选候选，不定最终版**：本轮候选只进入下一步多年验证，不直接替代主实验。

如果没有单一组合同时满足上述条件，则记录为“未找到可直接采用基线”，并建议扩展扫描或回到真实逐年 IC 数据需求。
