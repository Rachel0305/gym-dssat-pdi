# 031_28 SY all-year four-baseline completion prompt

## Purpose

Supplement the missing SYA 2005-2023 baseline envelope needed for 031_27 frozen MaskablePPO transfer interpretation.

This task is a baseline-completion task only:

- no PPO/DQN training;
- no change to 031_27 candidate policies;
- no invented recorded-farmer management;
- generated baselines must use the same all-year rendered DSSAT environment as 031_27.

## Background

031_27 evaluated the selected frozen SYA MaskablePPO candidates for all available SYA years, 2005-2023. Four-baseline comparisons were only available for SY2012, SY2014, and SY2015, so most SYA years could not be compared against null, DSSAT auto, recorded farmer, and official extension expert.

The 031_27 rendered `fileX.MZX` contains one synthetic treatment per year (`SimYYYY`) with manual irrigation/fertilization enabled and zero static application rows. Therefore:

- `null` can be generated by zero-action replay under manual management;
- `dssat_auto` was initially planned by changing simulation management to DSSAT automatic irrigation/fertilization (`IRRIG=A`, `FERTI=A`), but the 031_28 smoke test showed that the all-year rendered SYA template triggers a DSSAT Fortran error in `IRRIG.for` under automatic irrigation management. Therefore it must be marked unavailable in this all-year generated-baseline task rather than forced or substituted;
- `official_extension_expert` can be generated by applying the 018_03 Northeast/Great-Wall spring maize expert schedule to each SYA year;
- `recorded_farmer` cannot be generated for years lacking source recorded management rows, and must be marked unavailable rather than reconstructed.
