# Results 3.2 Discussion：天气增强分布特征与泛化收益有限的原因分析

## 一、任务背景

目前Gym-DSSAT论文的Results 3.2已经完成统计分析和图表制作。

章节标题：

**3.2 天气增强对跨年水氮管理表现的影响**

五个站点：

`SY`、`HL`、`LC`、`YC`、`FQ`

比较两条训练路线：

- `H`：历史天气训练组。
- `A`：天气增强训练组。

每组8个随机种子，共同评价年份为2014—2023年。

### 1. 已有研究发现

**发现一：天气增强没有带来一致的平均产量收益。**

相对于历史组，增强组的平均产量变化为：

| Site | Yield difference (kg/ha) |
|---|---:|
| SY | -482 |
| HL | -324 |
| LC | -329 |
| YC | -247 |
| FQ | +61 |

五站差异的探索性95% Bootstrap置信区间均跨零。

因此，目前没有充分证据证明天气增强能够一致改善平均产量，但也不能认定天气增强完全无效。

**发现二：水氮投入与生产率存在不同权衡。**

- SY、HL：平均产量下降，灌溉和施氮减少，`PFP_N`提高。
- LC、YC：平均产量下降，灌溉略微减少，施氮增加，`PFP_N`下降。
- FQ：平均产量小幅增加，施氮增加，`PFP_N`下降。

**发现三：天气增强没有一致改善年际产量稳定性。**

各站点年际产量标准差变化：

| Site | Delta SD (kg/ha) |
|---|---:|
| SY | -22.8 |
| HL | +145.2 |
| LC | +354.1 |
| YC | -191.0 |
| FQ | +57.4 |

其中HL的正向变化存在探索性信号，但Bootstrap与Welch区间的判断不同，不能作出稳健的显著性声明。

目前Results 3.2状态：

`READY_WITH_CAVEATS`

### 2. 本轮科学问题

原先天气增强的研究假设是：

**通过增加训练天气的多样性，使PPO学习到能够适应更多环境条件的水氮管理策略，从而改善未见年份的管理表现。**

但现有结果没有显示一致的正向收益。

本轮希望检验一个基础问题：

> 天气增强是否真正扩大了PPO实际接触的天气条件范围？这些新增天气条件与测试年份的气象分布是什么关系？

进一步区分以下可能情况：

1. 增强天气与历史训练天气区别有限。
2. 增强天气扩大了变化范围，但部分新增条件偏离评价期天气分布。
3. 增强天气扩大了合理的天气覆盖范围，但没有转化为稳定的管理收益。
4. 不同站点的天气增强幅度和覆盖程度存在明显差异。

上述情况只是待检验假设，不得预先认定任何一种成立。

本轮目标是为Discussion提供证据，而不是证明预设机制。

# 四、任务二：比较历史、增强和评价天气的分布

## 1. 选择气象指标

本轮不开展大规模气象特征挖掘。

首先检查实际天气增强方案修改了哪些气象变量。

然后优先评价具有明确农业意义的指标。

建议核心指标为：

**A. 生育季总降水量**

`seasonal_precipitation`

用于评价不同天气样本的整体降水条件。

**B. 生育季最长连续无雨天数**

`maximum_dry_spell`

用于评价持续无雨条件。

需要明确无雨日的降水阈值，例如根据项目既有定义采用`RAIN < 1 mm`。

不得在观察结果后反复调整阈值以获得预期结论。

**C. 生育季温度条件**

`seasonal_temperature`

根据实际增强变量，优先选择生育季平均最高温度或高温日数等一种主要指标。

**D. 太阳辐射**

`SRAD`

如果天气增强确实对太阳辐射进行了处理，或已有证据表明该变量的质量对站点结果非常重要，则纳入相应分析。

否则不强制增加。

如分析过程中发现其他变量属于增强方法的关键控制变量，可以补充，但必须解释其必要性。

## 2. 统一时间窗口

所有天气指标必须在可比较的时间窗口内计算。

优先使用项目已有的统一作物生长季或农业管理评价窗口。

如不同站点的作物季节不同，可以分别使用站点适用的固定窗口。

需要记录：

- 起始日期。
- 结束日期。
- 时间窗口的确定依据。
- 是否跨自然年。
- 是否存在缺失或异常日期。

不得随意使用全年气象指标替代农业生长季指标。

也不要因为不同策略导致作物实际生育期变化，就直接使用不同长度的时间窗口计算天气覆盖程度。

## 3. 比较三类天气分布

对于每个站点，比较：

`H vs A`

`H vs T`

`A vs T`

重点回答：

1. 天气增强是否扩大了训练天气的变化范围？
2. 增强天气是否引入了历史训练中较少出现的天气条件？
3. 增强天气是否覆盖了评价期内出现的主要气象变化？
4. 增强天气是否存在明显偏离真实观测气候特征的情况？
5. 五个站点的天气增强效果是否存在差异？

建议优先使用描述性统计：

- 均值。
- 标准差。
- 最小值与最大值。
- 适当的分位数。
- 天气分布图。

如需量化测试期覆盖程度，可以计算评价年份有多少落在历史训练天气和增强天气的经验范围内。

但要注意：

**覆盖范围更大不必然意味着天气增强更有效。**

而且测试期只有10年，覆盖比例应作为描述性证据，不应过度解释其统计精度。

## 4. 处理样本量与权重问题

历史训练天气、增强天气和评价天气的样本量可能不同。

例如，增强天气可能由大量随机生成样本组成。

要求：

1. 明确分布比较的基本单位，是日、天气年还是生育季。
2. 优先使用每个天气样本对应的生育季统计值进行比较。
3. 不能把同一条天气序列反复抽取的结果当成独立气候样本。
4. 如果训练抽样频次不均衡，应区分样本池分布与实际训练暴露分布。
5. 不能仅因为增强组样本数量更多，就认定其天气多样性更大。

本轮以描述性比较为主，不强制开展新的显著性检验。

**天气分布差异未能充分解释不同站点的管理表现。**
