# LCA CLI 参数拟合与审计任务

## 背景

已完成 SYA/LCA WGEN 前置方法学复审。

当前结论：

-   LCA：
    -   2005--2013 训练期 WTH 四变量 QC 通过；
    -   剩余 22 项非降水来源不确定值，占三变量训练单元格约 0.223%；
    -   已允许进入 CLI 参数计算与审计阶段；
    -   不允许直接进入随机天气生成。
-   SYA：
    -   暂不处理，本任务不涉及。

## 任务目标

仅完成 LCA 2005--2013 历史天气序列的 CLI 参数计算与审计。

不要生成随机天气，不运行 WGEN，不运行 DSSAT，不运行 PPO。

## 执行要求

1.  固定输入：

    -   站点：LCA
    -   训练年份：2005--2013
    -   使用当前冻结 WTH 文件
    -   保持输入文件 SHA256 不变

2.  固定天气定义：

    -   湿日定义： `RAIN > 0.0`

    -   保持与当前项目 `scripts/build_dssat_cli.py` 一致。

3.  计算 DSSAT CLI 所需参数：

    包括：

    -   湿日/干日 SRAD 均值和标准差；
    -   湿日/干日 TMAX 均值和标准差；
    -   TMIN 月均值和标准差；
    -   降水量统计；
    -   湿日数量；
    -   干后湿概率；
    -   Gamma 分布相关参数。

4.  重点审计：

    -   14×12 月度参数完整性；
    -   参数物理范围；
    -   1 月湿日样本量问题（约 4 个湿日）；
    -   Gamma 参数稳定性；
    -   22 个 provenance 标记位置是否影响参数异常。

5.  不修改：

    -   WTH 文件；
    -   配置文件；
    -   baseline；
    -   原始审计结果。

6.  输出：

    请生成：

    -   CLI 参数文件；
    -   参数审计报告；
    -   参数质量检查 JSON。

报告中明确说明：

-   CLI 参数是否可用于下一阶段 WGEN 输入；
-   哪些月份需要人工关注；
-   是否存在阻止 WGEN 的参数问题。

## 禁止事项

禁止：

-   运行 WGEN；
-   生成 synthetic weather；
-   修改天气数据；
-   修改 PPO 配置；
-   训练模型。

完成后停止，等待下一步授权。
