# 016_07 FQ 施氮时机响应诊断 prompt

## 目标

在已经确认 `FQ2008/FQ2016` 对施氮总量整体不敏感之后，继续检查：

- FQ 是否完全没有施氮响应；
- 还是只有某种特定施氮时机才会转化为产量差异。

## 已知前提

1. `016_05` 显示 FQ2008 / FQ2016 的高产组合主要来自灌溉响应。
2. `016_06` 在固定 `I60 critical` 下扫描 `N=0~300`，发现：
   - `FQ2008`: `GWAD` 基本完全不变；
   - `FQ2016`: `NSTRES` 可被小量氮压低，但 `GWAD` 仍不变。

## 诊断设计

固定条件：

- 年份：`FQ2008`, `FQ2016`
- 灌溉：固定 `I60 critical`（DAP 45/70 各 30 mm）
- 氮总量：固定 `N150`

只改变施氮时机模式：

1. `early`
   - DAP `1/20/40`
2. `critical`
   - DAP `40/55/70`
3. `late`
   - DAP `55/70/85`
4. `split_early_late`
   - DAP `1/40/70`
5. `single_critical`
   - DAP `55` 一次性施入

## 输出

- `GWAD`
- `CWAD`
- 最大 `SWFAC`
- 最大 `NSTRES`
- 最终 `DAP`
- 每个时机模式的 daily CSV

## 判定标准

- 如果不同施氮时机下 `GWAD` 仍几乎完全不变：
  - 可以基本确认 FQ 在当前研究框架下不具备可利用的施氮优化空间。
- 如果某一类偏后期或关键期施氮能明显提升 `GWAD`：
  - 说明 FQ 不是“没有施氮响应”，而是“对施氮时机敏感”。

## 原则

1. 不训练 RL。
2. 不覆盖旧结果。
3. 中文记录。
4. 低成本前向模拟优先。
