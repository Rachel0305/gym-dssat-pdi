# 多站点水氮联合优化定位小结

## 可以直接对导师说的话

目前我们已经把封丘站的问题诊断清楚了。封丘不是训练没学会施氮，而是在当前站点-年份-管理框架下，氮并不是能显著提高产量的主限制因子。我们先做了固定灌溉下的施氮总量扫描，再做了固定总量下的施氮时机扫描，结果都表明：无论把氮从 0 加到 300，还是把 150 kg/ha 的氮改成早施、关键期施、后期施，产量几乎都不变。因此，封丘站目前更适合作为“灌溉响应主导、施氮响应弱”的诊断站点，而不适合作为水氮联合强化学习的主成功案例。

相对地，禹城和海伦更适合作为主线站点。禹城站已经显示出“节水节氮仍可达到高产平台”的特征，海伦站则更容易产生有解释性的管理响应和策略差异。所以后续主线更合理的安排是：把联合优化的主要训练和展示放在禹城、海伦，把封丘保留为一个边界条件站点，用来说明并不是所有站点年份都存在同等强度的水氮联合优化空间。

## 站点定位表

| 站点 | 当前结论 | 适合的角色 | 现阶段建议 |
| --- | --- | --- | --- |
| HLA | 有较清晰的管理响应，适合继续打磨联合优化策略 | 主成功案例站点 | 继续做联合优化主线 |
| YC | 已出现“较少水氮投入仍可达高产平台”的信号 | 主成功案例站点 | 继续做联合优化主线 |
| FQ | 灌溉响应明显，但施氮总量和时机都几乎不改变产量 | 诊断/边界条件站点 | 暂不作为联合优化主线，保留为弱氮响应案例 |

## 封丘站目前最硬的证据

1. `FQ2008`：固定 `I60 critical` 下，`N0 -> N300`，`GWAD` 始终约为 `7890 kg/ha`。
2. `FQ2016`：固定 `I60 critical` 下，`N0 -> N300`，`GWAD` 始终约为 `8012 kg/ha`。
3. `FQ2008/FQ2016`：固定 `I60 + N150` 后，把施氮时机改成 `early / critical / late / split / single`，产量仍基本不变。

## 对论文叙事的帮助

这不是负面结果，而是一个很有价值的边界条件结论：强化学习是否值得做水氮联合优化，取决于站点年份本身是否存在可利用的双资源响应空间。封丘站告诉我们，有些场景主要是水限制而不是水氮共同限制，这种场景下联合优化的收益上限天然就低。
