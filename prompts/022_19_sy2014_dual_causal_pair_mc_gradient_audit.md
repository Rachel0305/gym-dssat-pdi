# 022_19 SY2014 双因果pair+MC最终梯度兼容审计

## 1. 最终收尾范围

本任务是最后三步中的第一步，只审计：

```text
L_total = L_MC + lambda65*L_pair65 + lambda110*L_pair110
```

- `L_pair65`：022_10/11三个受控状态，目标`Q(a1)-Q(a7)=ΔG0/1000`；
- `L_pair110`：022_17八个非别名状态，目标`Q(a0)-Q(a1)=ΔG0/1000`；
- 两组均使用组内mean SmoothL1，状态数3与8不会机械放大某组权重。

不加入软蒸馏/锚定loss。该机制没有受控真值和预先确定的权重来源，会重新打开调参范围。未经验证状态不要求复制旧网络，最终由真实在线季节指标验收。

## 2. 固定权重推导

对每个seed先计算共享层梯度范数，然后定义：

```text
lambda65_seed  = 0.5 * ||g_MC|| / ||g_65||
lambda110_seed = 0.5 * ||g_MC|| / ||g_110||
```

即两组因果pair各获得MC共享层梯度范数一半的预算，合计名义预算等于MC。最终统一权重取三个seed对应值的中位数，不扫描、不设下限、不按结果调整。

## 3. 虚拟审计

使用统一权重，对022_08 seed0/1/2 checkpoint各做一次不保存的`lr=1e-4`虚拟SGD步，检查：

1. `L_pair65`下降；
2. `L_pair110`下降；
3. `L_MC`相对增加不超过1%；
4. 共享层`g65`与`g110`余弦不低于-0.20；
5. 总组合梯度及全部输出有限。

单seed五项全满足才兼容。至少2/3兼容进入A；1/3为B；0/3为C；实现失败为D。B/C立即停止SY训练线，不设计新loss补丁。

## 4. 输出与边界

- 两组因果目标CSV；
- seed梯度范数、余弦、统一权重和虚拟步前后loss；
- JSON、PNG/SVG、中文记录；
- DQN训练0步、DSSAT调用0次、不保存更新模型；
- A分支才允许022_20唯一一次三seed离线训练。
