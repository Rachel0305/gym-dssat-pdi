# 015_09 HLA2010 / HLA2015 统一 DQN 100K 长训练 prompt

## 目标

在 HLA2010 / HLA2015 上，使用与 YC2014 统一 DQN 相同的：

- 算法：DQN
- 奖励：`max(0, delta_grnwt) - 1.0 * irrigation - 5.0 * nitrogen`
- 动作空间：9-action
- 预算：`I<=120 mm, N<=300 kg/ha`
- 单次上限：`I<=30 mm, N<=100 kg/ha`
- 最小间隔：7 天
- 管理模式：`IRRIG=L, FERTI=L`

做正式长训练，验证是否能在产量和 post-hoc 累积奖励上超过 DSSAT auto 和专家记录。

## 执行原则

1. 先做统一脚本的低成本 smoke test。
2. smoke 正常后，再进入 100K seed0。
3. 训练中每 10K 保存并评估 checkpoint，避免只看 final model。
4. 暂不同时改奖励、预算、窗口或算法。

## 当前决定

- 第一步：HLA2010，2K smoke，seed0
- 第二步：HLA2010，100K 正式训练，seed0
- 第三步：若 HLA2010 结果有增益，再同脚本跑 HLA2015，100K seed0

## 输出要求

1. `dqn_eval_daily.csv`
2. `checkpoint_summary.csv`
3. `event_summary.json`
4. checkpoint 过程图
5. 中文实验记录 MD

## 输出目录

```text
DSSAT_auto_validation/HLA_2004/hla_unified_dqn_long_train_015_09/
```

## 判据

- 若 best checkpoint 在产量和 reward proxy 上都超过 DSSAT auto / expert，则说明 HLA 主线具备可行性。
- 若只在 reward proxy 上更优但产量持平，则按“节水节氮追平”解释。
- 若 100K 后仍不超过已有基线，则说明该统一目标下 HLA 已接近平台，不再把“增加步数”当作首选改进方向。
