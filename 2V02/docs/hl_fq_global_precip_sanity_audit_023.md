# HLA / FQA 全球逐日降水产品合理性审计（023）

## 执行结论

本任务按只读方式比较项目当前 D222 与 GPCC Full Data Daily v2022、CPC Global Daily Precipitation V1.0 RT 的区域格点信号。最近格点是主分析；3×3 邻域只说明空间背景。两种产品都不是 HLA/FQA 本站逐日观测，且不能视为完全独立的证据。所有未解决日期继续缺测并标记 `REFERENCE_ONLY`；没有改写 D222、WTH、cleaned weather 或既有结果，也没有运行 WGEN、DSSAT、PPO。

- **HLA 2013：`REGIONAL_PRODUCTS_PARTIALLY_SUPPORT_D222`。** 两个产品都显示 2013 在本审计三年窗口内偏湿，且少数关键日期有共同区域强雨信号；但未共同支持全部极端日期或 178.2 mm 的站点量级。111 个缺测日仍未恢复。
- **FQA 2011–2013：`MIXED_OR_INCONCLUSIVE`。** D222 各年只覆盖 31–51 个数值日，不能检验完整年总量。240 mm 事件前后未见两产品区域强雨，204 mm 事件出现共同区域强雨背景，但最近格点值远低于 204 mm。157 个缺测日仍未恢复，天气不具备进入 WGEN 的条件。
- **建议：** 值得另行设计隔离的格点产品辅助填补敏感性方案，用于量化不同区域参考情景对事件、年量和后续结果的影响；本次结果不支持直接填补或宣称恢复了本站观测。

GPCC gzip NetCDF3 单年解压约 284 MB。程序按记录流式读取，仅保留目标格点周边值；CPC 按日块读取。没有落地 GPCC 解压副本，也没有将全球全年数组整体载入内存。

## 产品身份、来源和日界

- **GPCC Full Data Daily v2022：** 1°、逐日、雨量计资料驱动的陆地区域格点分析，降水单位 mm/day；文件含 `precip`、`interpolation_error` 与 `numgauge` 辅助变量。官方 v2022 资料期为 1982–2020，产品页目前也列有 v2025；本次遵守本地冻结输入，使用提供的 v2022 文件。[GPCC v2022 官方产品页](https://opendata.dwd.de/climate_environment/GPCC/html/fulldata-daily_v2022_doi_download.html)
- **CPC Unified Gauge-Based Analysis of Global Daily Precipitation：** 本地 NetCDF 标记 `CPC GLOBAL PRCP V1.0 RT`，0.5°、逐日、单位 mm；2011–2013 属 2006 年后的 RT 时段。本地文件只有降水、坐标和时间变量，没有雨量计数或质量辅助变量。官方 README 记载资料期自 1979 年起，并说明不同国家日累积结束时刻不同、EOD 信息有限且未充分核验。[CPC 官方产品 README](https://ftp.cpc.ncep.noaa.gov/precip/CPC_UNI_PRCP/GAUGE_GLB/DOCU/PRCP_CU_GAUGE_V1.0GLB_0.50deg_README.txt)

GPCC 使用国家气象/水文服务、区域/全球资料集和 WMO GTS 等来源；CPC 也整合多源雨量站资料。因此底层站源可能部分重叠，不能把两者说成独立本站观测。两套文件的纬度、经度表示规则格网中心；NetCDF 00:00 时间标签本身不能证明统一使用 UTC 日。CPC 文档还明确指出国家间日累积截止时间不同。本审计保留原始日期，D222 对照的 −1/0/+1 日偏移只作敏感性诊断，不平移任何序列。

产品版本、时间范围、坐标/维度、变量、单位、缺测值、辅助变量、SHA256 与源文件属性见 [产品身份文档](hl_fq_global_precip_product_identity_023.md) 和 [输入溯源 JSON](../results/hl_fq_global_precip_023/input_provenance.json)。

## 解释边界与后续

GPCC/CPC 表示 1°/0.5°区域分析，不是 HLA/FQA 单站实测；站点降水极值会被空间平均，产品之间还可能共享底层站资料。CPC 日累积截止时间存在国家差异。最近格点距离为约 25–53.5 km，也不代表雨量计所在位置。故不能直接用格点值替换 D222、不能将空白当作零，也不能把高相关或区域强雨称为本站日值验证。

建议在查看本审计后另行设计隔离的填补敏感性方案：保留原 D222 作为基线，另设明确标注的 GPCC/CPC 区域参考情景，比较降水事件、年/月总量与后续结论。该方案应继续报告“参考情景”，不得冒充观测恢复。本任务到此停止，未执行填补或下游模拟。
