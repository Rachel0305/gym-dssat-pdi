## 初步判读规则
- 如果 early_dap1_10 水氮显著下降，但产量相对 036 大幅下降，则说明约束过强或 reward 不支持后续补偿。
- 如果 early dump 被压住且产量/资源效率维持，则可考虑五站点扩展。
- 如果 agent 改成晚期集中补偿或产生高胁迫，则不能直接扩展，需要继续审计。
