# 022_06 SY2014 支持集内 Q 排序与预算动作别名离线审计

## 1. 目的

022_05 在训练和评估全过程中加入固定网格行为支持 mask 后，仅 1/4 checkpoint 通过联合主判据，且四个 checkpoint 均达到 N300。此结果说明未覆盖动作外推是参与因素，但支持 mask 不是充分修复。

本任务只回答两个问题：

1. 在已覆盖动作内部，DQN 的 Q 排序是否与 022_03 固定网格 Monte Carlo target 的描述性排序一致？
2. N300 是否主要是预算裁剪导致的动作别名假象，还是在预算尚未耗尽时就由所选动作真实执行形成？

## 2. 边界

- 纯离线读取，不训练、不调用 DSSAT、不修改 checkpoint；
- 读取 022_03 的 288 条固定网格 replay 数据、transition manifest；
- 读取 022_05 的四个 checkpoint、checkpoint stage actions 和结果汇总；
- 不修改 reward、IC、动作空间、支持集、阈值或训练季数；
- 不把后期不同历史状态下的经验均值写成严格因果反事实。

## 3. Q 排序审计

对 season15/30/45/60 checkpoint：

1. 在 288 个固定网格观测上计算九个动作的 Q；
2. 每个阶段仅在 022_05 冻结支持集内排序；
3. 汇总每个阶段/动作的平均 Q、平均 Monte Carlo target、样本数和成功/失败来源比例；
4. 计算阶段内平均 Q 与平均 target 的 Spearman 排序相关；
5. DAP1 的 48 个观测应为同一初始状态，单独作为最强可比证据；
6. DAP30 以后存在历史状态差异，只作描述性诊断，不作动作因果优劣结论。

## 4. 动作别名审计

对 022_05 已保存的 24 个 checkpoint 阶段动作：

1. 比较 requested 与 executed 水氮量；
2. 记录预算裁剪是否改变请求动作；
3. 计算每个决策前的剩余水氮预算；
4. 对该阶段全部支持动作执行同一预算裁剪，统计会映射到相同实际执行量的别名组；
5. 明确 N300 首次达到的阶段，以及达到 N300 之前实际执行的施氮量。

## 5. 预注册判定

- **A：Q 排序错位为主要信号**：DAP1 或多数阶段出现 Q 首选动作与平均 target 首选动作明显不一致；且 N300 在预算耗尽前由真实执行动作形成。下一步可考虑有监督的保守 Q/动作排序约束，但不得直接训练。
- **B：预算别名为主要信号**：N300 主要来自裁剪/别名记账，而非预算耗尽前的真实执行；下一步考虑 budget-exact action mask。
- **C：两者共存**：既有显著支持集内排序错位，也有会影响关键资源总量判断的别名。
- **D：证据不足**：现有数据无法区分，停止并记录缺失数据。

动作请求在预算耗尽后被裁剪为 0，只能证明存在别名；若 N300 已在此前由真实执行形成，不得把季节 N300 归因于后期别名。

## 6. 输出

- checkpoint×阶段×动作 Q/target 汇总 CSV；
- DAP1 同状态审计 CSV；
- checkpoint 阶段预算与别名 CSV；
- 阶段排序相关与判定摘要 JSON；
- Q-target 排序图 PNG/SVG；
- 中文实验记录。
