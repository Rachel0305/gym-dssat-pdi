## Interpretation boundary

This smoke only checks cross-station execution and gross behavior for the currently strongest free-timing PPO branch. Do not use it as a final all-years conclusion.

## Result interpretation

Branch: B.

The fixed 031_17/031_18 scaled-reward discrete MaskablePPO configuration successfully trained and evaluated on all five smoke site-years. This means the free-timing PPO pipeline is now technically portable beyond SYA2014.

However, the gross behavior is not yet clean enough for all-year expansion:

- all five site-years completed normally;
- all five learned non-trivial irrigation/fertilization policies;
- early nitrogen remains a cross-station pattern:
  - FQA2016: N160 by DAP10, total N240;
  - HLA2015: N120 by DAP10, total N240;
  - LCA2010: N160 by DAP10, total N240;
  - SYA2014: N240 by DAP10, total N240;
  - YCA2014: N120 by DAP10, total N160.
- HLA2015 and YCA2014 still show substantial N stress days despite early nitrogen.

This suggests that reward scaling solved a PPO numerical-stability issue, but did not solve the broader timing-rationality problem. The current branch should not yet be expanded to all station-years as a final method.

Recommended next step: run a focused timing-rationality diagnostic before all-year expansion. Specifically, quantify whether the early nitrogen actions are actually beneficial by running delete/downshift counterfactuals for the first N event(s) in the five smoke site-years. If early N is beneficial under DSSAT, it can be defended as preventive fertilization; if not, the reward/action design needs a timing penalty or phenology-aware constraint before full-scale runs.
