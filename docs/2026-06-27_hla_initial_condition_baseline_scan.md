# HLA 初始土壤水氮基线小扫描结果记录

## 1. 目的

HLA 2004-2023 的 IC=1 null 结果显示，直接把 2004 年初始土壤水氮剖面平移到所有年份后，多数年份在无灌溉、无施肥条件下也能达到 5-8 t/ha 籽粒产量。这说明该统一初始剖面显著改变了 null 基线。

本轮目标不是为了让 PPO 获胜而任意调参，而是寻找一个更适合作为水氮管理优化基线的初始条件：

- null 不应过高，否则人为管理空间不足；
- null 也不应过低到作物几乎不能正常生长；
- 初始条件需要有农学解释或项目已有文档支撑；
- 先低成本扫描，不训练 PPO。

## 2. 设计依据

项目已有文档：

- `docs/soil_water_and_nitrogen_initialization_summary.md`

其中水分初始化公式为：

```text
SH2O = SLLL + 0.55 * (SDUL - SLLL)
```

该公式把初始水分设在植物可利用水范围 `SDUL - SLLL` 的中等偏干位置。该文档同时说明 HLA 的矿质氮剖面是 record-based and preserved：

```text
@C  ICBL  SH2O  SNH4  SNO3
 1    20  0.26  22.7  10.1
 1    40  0.26  10.8  11.3
 1    60  0.26  15.1  12.5
 1    90  0.25   8.2   8.1
```

因此，本轮扫描的解释是：

1. 水分优先沿用已有 `0.55` 公式；
2. 初始矿质氮以 HLA 2004 record-based 剖面为上界；
3. 由于“把同一份 2004 剖面平移到所有年份”会让 null 过高，因此测试矿质氮保守缩放。

参考依据来自项目已有文档中列出的 DSSAT User's Guide、DSSAT soil water balance、FAO-56 作物蒸散等资料。当前没有找到逐年实测 HLA 初始矿质氮剖面，因此本轮结果只能作为“统一初始剖面敏感性诊断”，不能替代真实逐年 IC 数据。

## 3. 扫描设置

脚本：

- `src/scan_hla_initial_condition_baseline.py`

Prompt：

- `prompts/010_12_hla_initial_condition_baseline_scan.md`

输出目录：

- `DSSAT_auto_validation/HLA_2004/initial_condition_baseline_scan_010_12/`

固定项：

- 站点：HLA
- 作物：maize
- 管理：null，无灌溉、无施肥
- 模型：PDI/gym DSSAT 4.8.0
- 不训练 PPO

年份：

- 2004：异常低产关键年
- 2012：异常低产关键年
- 2009：追加的代表性高产/正常响应年，用来判断正常年份 null 是否仍然过高

选择这三个年份的理由：

1. **2004 是当前主实验年份，也是异常机制重点年。**
   - 之前大量 PPO、四情景图、IC=0/IC=1 对比都围绕 HLA 2004 展开；
   - IC=1 下 2004 出现“生物量明显增加但籽粒仍为 0”的现象；
   - 因此 2004 必须纳入，用来判断新 IC 是否会改变主实验结论。

2. **2012 是另一个异常低产年份，用来检查候选 IC 是否会抹平异常年。**
   - IC=0 与 IC=1 下 2012 籽粒都为 0；
   - 如果某个 IC 组合把 2012 直接变成高产，说明这个 IC 可能过强；
   - 因此 2012 用作异常年份鲁棒性检查。

3. **2009 是代表性高产/正常响应年份，用来检查 null 是否仍然过高。**
   - 只看 2004/2012 会偏，因为异常年份本身很难形成籽粒；
   - 原 IC=1 下，2009 null 籽粒产量约 8 t/ha，是“初始剖面过强”的典型表现；
   - 因此追加 2009，检查候选 IC 能否把正常年份 null 降到合理区间，同时仍允许作物形成籽粒。

三者的诊断分工可以概括为：

```text
2004 = 主实验年份 / 异常机制重点
2012 = 异常年份鲁棒性检查
2009 = 正常或高响应年份的 null 过高检查
```

变量：

- 水分 fraction：`0.35, 0.45, 0.55, 0.65`
  - 公式：`SH2O = SLLL + fraction × (SDUL - SLLL)`
- 初始矿质氮缩放：`0.25, 0.50, 0.75, 1.00`
  - 对 HLA record-based `SNH4/SNO3` 同比例缩放

组合选择理由：

- 本轮不是九组，而是每个年份 **4 × 4 = 16 组**；三个年份共 48 次模拟。
- 水分 fraction 围绕已有项目设定 `0.55` 展开：
  - `0.55` 是已有文档采用的中等偏干设定；
  - `0.35`、`0.45` 测试更干初始水分；
  - `0.65` 测试稍湿初始水分；
  - 目的是判断初始水分是不是导致 null 过高的主导因素。
- 氮素 scale 以 HLA 2004 record-based 剖面为上界：
  - `1.00` 为原始 record-based 剖面；
  - `0.75` 为轻度保守缩放；
  - `0.50` 为中度保守缩放；
  - `0.25` 为强保守缩放；
  - 目的是判断初始矿质氮是不是导致 null 过高的主导因素。
- 选择粗网格而不是细网格，是为了节省算力、先判断方向。如果粗网格显示某个区间有价值，再进入下一轮加密扫描。

总模拟次数：

- 3 年 × 4 个水分 fraction × 4 个氮缩放 = 48 次 DSSAT 前向模拟

## 3.1 候选筛选标准

本轮候选不是按“产量最高”选择，而是按“是否适合作为管理优化基线”选择。

筛选标准：

1. **正常年份 null 不能过高。**  
   以 2009 为代表，若 null 接近 7-8 t/ha，说明无管理已经高产，施肥/灌溉/PPO 的管理空间不足。

2. **异常年份不能被抹平。**  
   2004、2012 不应被某个 IC 组合直接抬成正常高产，否则该 IC 可能过强，改变了年份差异。

3. **作物仍需能生长。**  
   正常年份至少应能形成籽粒；异常年份也应有一定生物量响应，而不是完全没有生长。

4. **胁迫指标应保留响应空间。**  
   WSPD/NSTD 不应全程无变化，也不应全程极端饱和。后续灌溉和施肥应仍有可影响模型过程的空间。

5. **解释优先于拟合。**  
   水分优先选择已有文档支持的 `water_fraction=0.55`；氮素缩放若降低，需要解释为“统一多年初始剖面的保守缩放”，不能说成真实逐年实测值。

6. **本轮只选候选，不定最终版。**  
   候选组合只进入下一步 HLA 2004-2023 多年 null 验证，不直接替代主实验。

## 4. 主要结果

### 4.1 初始水分 fraction 影响较小

在 2009 年，水分 fraction 从 0.35 到 0.65，null 籽粒产量变化很小；真正决定产量层级的是矿质氮缩放。

这说明当前 HLA null 高产问题主要不是初始水分过高造成的，而是初始矿质氮供给过强。

### 4.2 初始矿质氮缩放是关键

2009 年结果：

| N scale | 2009 null 籽粒产量范围 |
|---:|---:|
| 0.25 | 2842-2869 kg/ha |
| 0.50 | 7266-7413 kg/ha |
| 0.75 | 8027 kg/ha |
| 1.00 | 8027 kg/ha |

解释：

- `N scale=1.00` 和 `0.75` 基本维持高产 null；
- `N scale=0.50` 仍然过高；
- `N scale=0.25` 把正常年份 null 降到约 2.85 t/ha，更能保留施肥管理空间。

### 4.3 2004 和 2012 异常没有被完全抹平

2004：

- 大多数组合籽粒产量仍为 0；
- 只有 `water_fraction=0.65, N_scale=1.00` 形成约 1531 kg/ha 籽粒；
- 在候选 `water_fraction=0.55, N_scale=0.25` 下，籽粒为 0，生物量约 3478 kg/ha。

2012：

- 所有组合籽粒产量均为 0；
- 生物量约 1630-1645 kg/ha；
- 说明 2012 零籽粒可能更多与年份气象/物候/生殖过程有关，不能仅靠初始水氮解释。

## 5. 当前推荐候选

暂定候选：

```text
water_fraction = 0.55
N_scale = 0.25
```

理由：

1. `water_fraction=0.55` 沿用项目已有文档中的水分初始化公式，有明确解释；
2. `N_scale=0.25` 是本轮扫描中唯一能把 2009 null 从 8 t/ha 降到约 2.85 t/ha 的矿质氮水平；
3. 该组合没有把 2004 和 2012 异常年份直接“救成高产”，保留了年份异常；
4. 该组合下 2009 仍能形成籽粒，说明作物不是完全不能生长；
5. null 约 2.85 t/ha，仍给灌溉/施肥/PPO 管理留下增产空间。

候选初始剖面为：

```text
@C  ICBL  SH2O  SNH4  SNO3
 1    20  0.264  5.67  2.52
 1    40  0.259  2.70  2.83
 1    60  0.259  3.77  3.12
 1    90  0.247  2.05  2.02
```

注意：这不是最终主实验 IC，只是当前最值得进入下一轮验证的候选。

## 7. 当前结论

本轮小扫描支持以下判断：

1. HLA 多年 IC=1 null 过高，主要是初始矿质氮供给过强，而不是初始水分过高；
2. 保留 `SH2O = SLLL + 0.55 × (SDUL - SLLL)` 是合理的，因为它已有项目文档和土壤水分概念支撑；
3. 对 record-based HLA 2004 矿质氮剖面做保守缩放是必要的，否则统一平移到多年会让 null 基线过强；
4. 当前最合理的候选是 `water_fraction=0.55, N_scale=0.25`；
5. 但该候选还不能直接用于全部主实验，需要先做下一步验证。

## 8. 下一步建议

建议下一步不要直接训练 PPO，而是继续低成本验证候选 IC：

1. 用候选 `water_fraction=0.55, N_scale=0.25` 跑 HLA 2004-2023 全部 null；
2. 与 IC=0、原 IC=1 多年 null 产量和胁迫对比；
3. 如果多年 null 分布合理，再在 HLA 2004 做四情景小规模对照；
4. 最后再决定是否把候选 IC 推广到其他站点，或是否需要站点分别校准。
