# 022_14 SY2014 pairwise+MC 唯一一次离线训练的预算审计

## 1. 背景与目的

022_12 证明受控 pairwise 目标与原 MC 回归在三个 seed 上不存在预注册定义下的严重梯度冲突，但一次 `1e-4` 虚拟步只使 `Q(a1)-Q(a7)` 改善约 `1e-4`。本任务在正式离线训练之前估算纠正 DAP65 排序所需的更新预算，避免机械沿用 022_08 的 2000 次更新后才发现预算不足。

本任务是数值审计，不是训练实验：DQN 正式训练 0 步、DSSAT 调用 0 次、未保存更新后的 checkpoint。

## 2. 固定设置

统一权重按 022_12 三个 seed 的共享层梯度范数比值中位数固定：

```text
lambda_fixed = 0.0060048738917845
```

不设置 lambda 下限、不扫描权重。所有 seed 使用同一权重。

对每个 seed×三个受控 DAP65 前缀，在该统一 lambda 下重新计算一次不保存的虚拟 combined step。学习率固定为 `1e-4`。

## 3. SmoothL1 区域核对

九组初始 pairwise 残差为 `0.515–0.908`，全部满足 `|residual|<1`，已经位于 SmoothL1 的二次区，而不是先处于线性区再逐渐进入二次区。

因此同时报告：

- 恒定单步改善的线性外推；
- 在局部 Jacobian 近似不变时，残差按当前比例几何收缩的二次区外推。

后者仍只是经验近似。正式训练中网络参数、MC 梯度、Jacobian 和优化器轨迹都会改变，不能将其解释为收敛保证。

```text
下一次唯一离线训练固定预算 = 3000 updates
```

达到因果目标 `+0.5` 的 90% 所需局部估算最高约 14008 步。但下一轮的首要目标是纠正 `action1/action7` 排序，而不是精确拟合完整 margin，因此不据此把训练扩大到 15K。

## 5. 结论边界

可以确认：

- `lambda_fixed` 小不等于加权后的 pairwise 梯度贡献小；该权重来自共享层梯度范数对齐；
- 原 2000 次预算对最慢的 seed1/W120 状态可能不足；
- 3000 次是按预注册公式得到的最小统一预算，不是结果出来后追加的安全倍数。

不能确认：

- 3000 次一定能翻转全部排序；
- 排序翻转后一定能改善在线 DQN；
- 局部外推在几千步范围内保持精确。

## 6. 下一步硬边界

只允许一次统一配置的离线 MC+pairwise 训练：

- 三个 seed；
- 同一 `lambda_fixed=0.0060048738917845`；
- 固定 3000 updates；
- 不扫描 lambda、不临时增加步数；
- 先检查 DAP65 三前缀排序是否全部纠正，再检查 MC 回归、留出阶段排序与 DAP1/110 是否退化；
- 未通过则按预注册结果停止，不现场救参；
- 即使通过，也只能说明离线排序约束有效，不能直接宣称在线策略成功。

`022_13` warm-start 草案继续保持暂停，不得在上述一次性离线训练之前启动。
