# 043_02 SYA lowIC 天气预报归一化 binary-timing MaskablePPO 记录

## 本轮结论边界

- 本轮是在 042_10 binary-timing PPO 基础上加入天气/完美预报输入和固定物理尺度归一化。
- 不使用 teacher warm-start，因此不能把结果解释为 teacher 带来的提升。
- reward 继承主线，并加入 042_02 已使用过的氮胁迫过程惩罚；本轮不扫描系数。
- 训练步数：`100000`；checkpoint：`25000, 50000, 75000, 100000`。

## 固定配置

- lowIC 输入目录：`DSSAT_auto_validation/multisite_new_cultivar_inputs_013_lowIC_manual`
- 灌溉档位：`[0.0, 45.0]`
- 施氮档位：`[0.0, 80.0]`
- observation：基础 25 维 + 天气/预报 5 维 = `30` 维。
- 天气/预报变量：`['rain_today_mm', 'tmin_today_c', 'rain_past7_mm', 'rain_future7_mm', 'tmean_future7_c']`
- 安全约束：继承 040_36，包括 7 天间隔、季节上限、DAP90 后禁氮、晚期灌溉保留 mask。
