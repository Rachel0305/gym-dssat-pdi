# 041 封丘 D222 降雨规则落地与 WGEN 拟合输入恢复

## 目标

仅处理 FQA（封丘）2005-01-01 至 2013-12-31 的 WGEN 拟合天气，先完成逐日天气和静态 CLI。HLA 留待独立阶段；本阶段不运行 DSSAT、WGEN 随机天气、PPO 或多 seed 训练。

## 本次用户决策

1. CERN/国家生态科学数据中心 D222 为封丘降雨主来源，取 `20-20合计(mm)`；原表有值日照录，包括 2012-09-02 的 240.0 mm 与 2013-05-26 的 204.0 mm。不因其他来源量级不同而改动、删除或继续把极值外部复核作为前置门槛。
2. D222 雨量空白按无雨 0 mm 转换，用于本次模型拟合。这是明确的数据处理规则；逐日保留原格状态与转换标记，不把转换后的 0 称作原表实测零值。
3. 旧审计所称 2013 年 157 个“未获外源确认日”不再单独阻断本规则下的 FQA 输入构建。旧报告保留，不覆盖；本次新结论以独立产物记录。

## 冻结范围与来源

- FQA 拟合期严格为 2005–2013，不加入 2004，不读取 2014–2023 作拟合或偏差校正。
- 降雨读取项目内完整 D222 原始工作簿 `data/external/人工大气观测降雨蒸发能见度日值.xls`；温度、辐射读取原始 `my_data/T2.xls`、`my_data/D32.xls`。
- 温度与辐射仅在原值缺失或此前已确认的物理异常日，使用 008 审计中通过筛选的训练期 NASA POWER 偏差校正候选；不得替换有效本站值。候选表为 `results/hl_fq_random_weather_8seed/source_audit/nasa_candidate_gapfill.csv`。
- 复用 `scripts/build_dssat_cli.py` 的 WGEN 月参数计算，不改旧脚本。FQA CLI 使用 `CNFQ`、2005 起始、9 年期限，以及经核对的站点经纬高程。不得把 YC 的 2004/10 年硬编码带入封丘。

## 执行与停止条件

1. 只读确认输入文件哈希、字段、站点日期行、候选记录；如果所需原始文件或候选缺失，停止并写明缺口。
2. 新建 `results/fqa_weather_resume_041/`，输出逐日 `DATE,RAIN,SRAD,TMAX,TMIN`、每个变量的来源标记、原始雨量格是否空白、年度汇总、输入 manifest 与机器可读 QC。
3. 逐日检查 3,287 个日期连续无重复、四变量有限、RAIN/SRAD 非负、TMAX ≥ TMIN；核对 D222 每个有值日与最终 RAIN 完全相同，空白日恰为 0，温度/辐射候选只覆盖指定缺失/异常位置。
4. 仅在逐日 QC 通过时拟合 12 个月 WGEN 参数，生成隔离 `CNFQ.CLI`，检查 12 个月、固定列宽和静态参数回算；保存 CLI 和输入哈希。CLI 只是静态候选，运行时读取与随机天气分布尚未验证。
5. 任何失败均保留诊断，不修改原始 `.xls`、已有 `.WTH`、旧审计、训练脚本、reward、wrapper 或评估结果。不得因本次静态通过而启动正式训练。

## 输出

新增中文报告 `docs/fqa_weather_resume_041.md`，明确 `FQA_FITTING_WEATHER` 与 `FQA_STATIC_CLI` 两个门禁状态、已采用的空白转零规则、待办的单季 runtime smoke 和随机天气 QC。后续 HLA 单独处理 2004 连续空白及原生 FIELD 坐标。
