# 021_08 SY2014 两个冻结窗口的 replay 与探索差异离线审计

## 状态

- 新训练：**未进行**
- DSSAT 调用：**未进行**
- 两个窗口新增 transition 提取：**completed**
- 请求动作与 reward 分布审计：**completed**
- 单条 transition 的探索/贪心来源恢复：**不可完成，历史数据未保存**
- wrapper 实际执行动作恢复：**不可完成，replay 只保存请求动作**
- 因果根因：**尚未确认**

## 目的

021_07 发现：5K–10K 与 15K–20K 两个 target 冻结窗口都存在广泛 online Q 排序漂移，因此“target 冻结窗口长度”不能单独区分是否坍缩。本轮继续保持零训练成本，比较两个窗口真正不同的探索率、replay 请求动作和标量 reward 构成：

- 5K–10K：10K 仍是高产候选；
- 15K–20K：20K 氮动作坍缩，但灌溉仍保持 I120。

## 方法

### 精确提取窗口新增经验

replay buffer 是容量 10,000 的环形数组。没有直接比较整个 checkpoint buffer，而是读取窗口起点 buffer 的 `pos`，再从窗口终点 buffer 中提取该位置至终点 `pos` 之间新写入的 transition：

| 窗口 | 起点 pos | 终点 pos | 提取数 | 环境步数差 |
|---|---:|---:|---:|---:|
| 5K–10K | 4,999 | 9,998 | 4,999 | 5,000 |
| 15K–20K | 4,997 | 9,996 | 4,999 | 5,000 |

每个窗口少1条是 `NStepReplayBuffer` 的 n-step 排队边界，不是丢失文件。

### 可审计与不可审计内容

保存的 replay 可以直接审计：请求动作索引、观测、标量 reward、done 和 timeout。

不能直接恢复：

1. 请求动作经预算/窗口/7日间隔裁剪后的实际执行动作；
2. 每条动作当时来自 epsilon 随机探索还是 greedy 选择；
3. 标量 reward 中产量增益、水成本和氮成本的精确逐项分解。

本轮额外计算“历史请求动作是否等于窗口终点网络在同一观测上的 greedy argmax”，但这只是事后对照，不能冒充动作生成时的真实来源。

## 核心结果

| 指标 | 5K–10K（未坍缩） | 15K–20K（坍缩） | 变化 |
|---|---:|---:|---:|
| 起点 epsilon | 0.729 | 0.186 | -0.543 |
| 终点 epsilon | 0.457 | 0.050 | -0.407 |
| 请求正灌溉比例 | 65.5% | 65.2% | -0.3个百分点 |
| 请求正氮比例 | 61.6% | 45.5% | -16.1个百分点 |
| 水氮同时为正 | 37.7% | 21.9% | -15.8个百分点 |
| N0请求 | 38.4% | 54.5% | +16.1个百分点 |
| N50请求 | 30.5% | 17.9% | -12.6个百分点 |
| N100请求 | 31.2% | 27.7% | -3.5个百分点 |
| no-op请求 | 10.6% | 11.2% | +0.6个百分点 |
| 归一化动作熵 | 0.987 | 0.860 | -0.127 |
| 与终点greedy一致（事后） | 24.0% | 49.4% | +25.4个百分点 |

第二窗口并不是整体转向 no-op：正灌溉请求几乎完全不变，no-op只增加0.6个百分点；变化集中在施氮侧，尤其 N50 请求明显减少。动作1（请求 I15/N0）的比例从18.6%升至37.2%，是第二窗口最常见动作。该模式与确定性评估中“保留灌溉、丢弃施氮”的坍缩形态一致。

动作熵下降、请求动作与终点 greedy 网络的一致率升高，也与探索率下降同步。但由于 replay 没保存逐条探索来源，不能把这组相关性写成“epsilon 降低导致坍缩”的因果结论。

## reward 分布

| 指标 | 5K–10K | 15K–20K |
|---|---:|---:|
| reward均值 | 24.95 | 23.57 |
| 正reward比例 | 0.620% | 0.620% |
| 负reward比例 | 5.10% | 6.00% |
| 零reward比例 | 94.28% | 93.38% |
| 最大reward | 5796.81 | 5777.82 |
| 有效终止样本比例 | 0.620% | 0.620% |

两窗口正 reward 比例与终止样本比例完全一致，说明正向信号主要集中在季末；第二窗口标量 reward 均值仅小幅下降，但负 reward 样本略增。由于没有保存 reward 组件和实际执行动作，不能进一步断言是哪一项成本造成差异。

## 综合判断

021_08确认了一个比“整体策略坍缩”更精确的事实：

1. 第二窗口的经验分布发生**氮侧定向变化**，并非水氮动作共同消失；
2. 该变化与 epsilon 到达0.05、动作熵下降、策略更接近终点 greedy 网络同时出现；
3. 这与 021_05 的修复结果一致：探索时间轴修复把坍缩推迟到 epsilon 接近下限的阶段；
4. 但现有离线数据仍不能区分“探索率降低导致Q偏差固化”与“Q漂移先使策略放弃氮、随后改变buffer”这两个方向。

因此，当前证据比“缩短 target interval”更支持优先检验探索衰减时间轴，但仍只能支持**单变量因果对照**，不能直接修改正式配置。

## 下一步建议

若继续，建议单独立项做一个最低成本的探索调度对照：

- 站点年份与 seed：SY2014 seed0；
- 保持 reward、IC、target interval、动作/预算/观测、学习率及其他 DQN 参数不变；
- 只延长 `exploration_fraction`，使 epsilon 在 20K 时尚未到达0.05；
- 先做 smoke 验证探索率曲线、日志和内存，再最多跑到25K；
- 前瞻记录 checkpoint loss、TD error、分动作Q、请求动作分布；
- 判定重点不是单个高产尖峰，而是15K–25K是否不再出现“N300→N0、产量坍缩”；
- 即便改善，也必须表述为该候选机制得到支持，不能立即推广到五站点。
