# 037_01：036 主线 PPO 措施问题类型审计记录

## 任务边界
- 不训练、不重跑 DSSAT、不修改 reward 或动作约束。
- 本任务只判断 036 措施问题主要属于频繁操作，还是早期集中投入。

## 预注册判据
- 频繁/碎片化：灌溉事件数 > 4，或施氮事件数 > 4，或同类操作间隔 < 7 天。
- 早期集中投入：DAP1-10 灌溉或施氮占季节总量 >= 80%。
- 预防性操作不直接判错，只作为解释性标签。
