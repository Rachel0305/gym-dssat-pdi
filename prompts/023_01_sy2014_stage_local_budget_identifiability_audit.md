# 023_01 SY2014 阶段局部训练预算与可识别性审计

## 1. 目的

023_00 已证明六个 `25-64-64-9` Q 网络在参数、优化器和输出上可以严格隔离。本任务不训练 DQN、不调用 DSSAT，只回答：在每阶段仅有 36 条训练 transition、单阶段网络仍有 6,409 个参数的条件下，DAP65 与 DAP110 的局部 MC+因果排序目标是否具有可用梯度，以及唯一一次离线训练应预注册多少更新。

## 2. 固定事实与边界

- 原共享网络：6,409 参数 / 216 条训练 transition，约 29.67 参数/样本；
- 阶段独立网络：每阶段 6,409 参数 / 36 条 transition，约 178.03 参数/样本，是原来的 6 倍；
- 只有 DAP65 和 DAP110 已有受控 DSSAT 因果标签；
- DAP1、30、50、85 在下一次训练中冻结，不因缺少因果证据而继续拟合；
- DAP65 使用三组 `Q(a1)-Q(a7)` 因果目标；
- DAP110 使用八组 `Q(a0)-Q(a1)` 因果目标；
- MC target、数据拆分、动作 mask、网络结构、学习率 `1e-4` 和三个 seed 均保持不变；
- 正式训练 0 步，DSSAT 调用 0 次，不保存更新后的 checkpoint；
- 不扫描网络大小、学习率、loss 权重或训练步数。

## 3. 审计内容

1. 逐阶段核对训练/测试样本数、动作覆盖、参数/样本比与 target 分布；
2. 对 seed0/1/2 从 022_08 checkpoint 初始化阶段 ensemble；
3. 分别在 DAP65、DAP110 计算阶段局部 MC loss、因果 pair loss 及完整参数梯度；
4. 权重按阶段内梯度范数预先推导：`lambda_stage=||grad_MC_stage||/||grad_pair_stage||`；两阶段不共享 lambda；
5. 用学习率 `1e-4` 做一次不保存的虚拟联合梯度步，核对：
   - 因果 loss 必须下降；
   - MC loss 相对增幅不得超过 1%；
   - 数值必须有限；
6. 对每个因果状态记录初始 margin、目标 margin、单步改善和 SmoothL1 所在区间；
7. 参考 022_14 的局部外推方法，分别估算排序翻转所需更新，并明确它不是收敛保证；
8. 统一训练预算取两个阶段、三个 seed、全部因果状态中最大局部翻转估算，向上取整到最近 500 次更新；不得额外添加事后安全倍数。

## 4. 预注册判据

仅当以下条件全部满足，判为 `A_budget_identified`：

- 六阶段各有 36 条训练和 12 条测试 transition；
- DAP65、DAP110 的受控动作在原数据中均有可识别支持；
- 3/3 seed 的两个阶段 MC/pair 梯度范数及 lambda 均为正且有限；
- 3/3 seed 的两个阶段虚拟步均降低 pair loss；
- 3/3 seed 的两个阶段虚拟步 MC loss 相对增幅均不超过 1%；
- 全部因果状态的目标 margin、当前 margin 与局部改善均有限，且局部改善为正；
- 能得到有限、正的统一预注册训练预算。

否则判为 `C_budget_not_identified`，停止，不进入离线训练。

## 5. 后续硬边界

若通过：另立 023_02，使用本任务冻结的两个阶段权重与统一预算，对三个 seed 仅训练 DAP65/DAP110；其余四阶段严格冻结。至少 2/3 seed 同时通过 DAP65 3/3、DAP110 8/8、MC guardrail 后，才允许另立 023_03 做 DSSAT 在线验证。

若失败：不现场调权重、加步数或缩小网络；记录失败并停止该结构路线。
