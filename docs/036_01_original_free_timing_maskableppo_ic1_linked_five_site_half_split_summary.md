# 036_01 原自由时序 MaskablePPO 重跑短版总览

## 任务性质

036_01 是正式主线重跑，不是 reward 调参。

本次只承认两个底层修复：

1. 使用 `DSSAT_auto_validation/multisite_new_cultivar_inputs_013` 输入源，并在 036_00 确认 `IC=1`；
2. PPO 动态 treatment 使用 `IRRIG=L, FERTI=L`，确保动作真实进入 DSSAT。

其他训练框架保持 032_22 不变：

- 算法：MaskablePPO；
- 每站点单独训练；
- half-split：前半年份训练，后半年份验证；
- seed：0；
- 每站点训练 100,000 steps；
- checkpoint：25K / 50K / 75K / 100K；
- 每日运行、每日观察；
- 灌溉档位：`{0, 15, 30, 45}` mm；
- 施氮档位：`{0, 40, 80, 120}` kg/ha；
- 灌溉/施氮最小间隔：7 天；
- 单季灌溉上限：160 mm；
- 单季施氮上限：250 kg/ha；
- DAP90 后禁氮；
- reward：原 032_22 stress-aware reward。

035_04/035_06 的 reward 改动不属于本次正式主线，只作为旁支探索保留。

## 当前必须标注的数据边界

1. `gap_wp_et_vs_four_max` 目前全为 `NA`，说明 036_01 当前比较表还没有接上可用的四情景 WP_ET 对照；不能据此判断 WP_ET 是否超过四情景。
2. SYA 的 `baseline_rows=0`，因此 SYA 与四情景最高值的 gap 目前不可解释，需要补齐或修正基线匹配后再判断。
3. FQA 2018 出现 PPO `final_grnwt=0`，需要后续单独核查是模型真实失败、DSSAT 输出异常，还是该年份输入/物候导致的特殊情况。

## 初步口径

036_01 完成了五站点 100K 正式重跑，确认主线训练流程在 `IC=1 + linked action` 条件下可执行。

但当前不能直接拿 036_01 作为最终汇报结果，因为 WP_ET 对照列缺失、SYA 四情景基线未匹配、FQA 2018 产量为 0 需要核查。下一步应优先做统一基线/指标后处理，而不是立刻改 reward 或继续调参。
