# 021_12 SY2014 target 更新幅度与五站点 reward 量级离线审计

## 1. 背景与问题

021_09–021_11 表明，修复探索率调度并延长探索后，SY2014 的高产策略可以维持或在下降后恢复，但 seed1 仍在 10K–25K 之间出现 11046→7352→10794 kg/ha 的大幅波动。021_11 又发现，target 更新既与策略下降同步出现，也与策略恢复同步出现，因此不能简单把 target 更新说成“好”或“坏”。

本轮只做离线分析，回答：

1. target 参数每次实际改变多少，是否与固定状态上的 Q 值和动作排序重组同步；
2. SY 的 reward 数值尺度相对其他站点究竟高多少；
3. 是否有足够依据进入一次显式 reward 缩放 smoke test。

## 2. 边界

- 未训练；
- 未调用 DSSAT；
- 未修改 reward、IC、动作空间、预算、探索率、target interval 或观测空间；
- 复用 021_09 seed0、021_10 seed1 的 10K/15K/20K/25K checkpoint；
- 复用 021_06 保存的 18 个真实固定观测和 9 动作映射；
- 样本只有 4 次 target 更新事件和 2 次冻结事件，只做描述性对照，不做统计因果推断。

## 3. 方法

### 3.1 网络参数变化

对相邻 checkpoint 的 online/target 网络参数计算：

- 参数绝对 L2 变化；
- 相对于窗口起点参数范数的 L2 变化；
- `_n_calls`、epsilon 和 target 是否实际改变。

### 3.2 固定状态 Q 变化

把完全相同的 18 个观测输入每个 checkpoint，计算：

- 9 动作 online/target Q 的平均和最大绝对变化；
- 每个观测、每个灌溉档位下 N0/N50/N100 完整排序改变数（共 54 组）；
- 18 个观测的全局 argmax 动作改变数。

### 3.3 reward 量级证据

自动读取 `021_01`、`021_09`、`021_10` 的正式 `selected_checkpoint.json`，排除名称含 `smoke` 的实验。HLA 在这些标准化审计范围内没有可直接读取的同口径选中结果，因此标记缺失，不用旧文档数字填补。

这些历史结果仍受旧训练协议问题或候选配置限制，因此 reward 跨站点比较统一标记为 **provisional（暂定证据）**，只能用于判断数值尺度假设是否值得继续测试，不能恢复为正式科学结论。

## 4. 结果

### 4.1 target 参数变化

| seed | 窗口 | target更新 | target相对L2变化 | online相对L2变化 |
|---:|---|---|---:|---:|
| 0 | 10K–15K | 是 | 0.5445 | 0.2436 |
| 0 | 15K–20K | 否 | 0.0000 | 0.1890 |
| 0 | 20K–25K | 是 | 0.3793 | 0.1921 |
| 1 | 10K–15K | 是 | 0.5468 | 0.2917 |
| 1 | 15K–20K | 否 | 0.0000 | 0.2530 |
| 1 | 20K–25K | 是 | 0.5312 | 0.2265 |

target 冻结窗口的 target 参数变化严格为 0，和 021_07/021_11 的哈希与计数审计一致。四次 target 更新的相对 L2 变化范围为 0.379–0.547，说明更新不是微小扰动。

### 4.2 固定状态上的 target-Q 重组

| seed | 窗口 | target更新 | target平均绝对Q变化 | target完整氮排序改变/54 | target argmax改变/18 |
|---:|---|---|---:|---:|---:|
| 0 | 10K–15K | 是 | 90.55 | 51 | 18 |
| 0 | 15K–20K | 否 | 0.00 | 0 | 0 |
| 0 | 20K–25K | 是 | 17.32 | 51 | 11 |
| 1 | 10K–15K | 是 | 45.15 | 50 | 16 |
| 1 | 15K–20K | 否 | 0.00 | 0 | 0 |
| 1 | 20K–25K | 是 | 15.26 | 29 | 9 |

target 更新都伴随大规模 target-Q 重组；冻结窗口则完全不变。但参数相对变化幅度与 Q 变化幅度并不呈稳定单调关系：例如 seed0 的两次更新相对 L2 为 0.5445 和 0.3793，平均绝对 target-Q 变化却分别为 90.55 和 17.32。仅凭 4 个更新事件不能声称“更新越大，策略越不稳定”。

### 4.3 online 网络在 target 冻结时仍继续漂移

| seed | 窗口 | target更新 | online平均绝对Q变化 | online完整氮排序改变/54 | online argmax改变/18 |
|---:|---|---|---:|---:|---:|
| 0 | 10K–15K | 是 | 16.74 | 37 | 7 |
| 0 | 15K–20K | 否 | 4.84 | 37 | 9 |
| 0 | 20K–25K | 是 | 13.55 | 33 | 8 |
| 1 | 10K–15K | 是 | 14.18 | 25 | 8 |
| 1 | 15K–20K | 否 | 4.38 | 17 | 6 |
| 1 | 20K–25K | 是 | 9.48 | 39 | 12 |

target 冻结并不等于策略停止变化。特别是 seed0 15K–20K，online 完整氮排序仍改变 37/54，与更新窗口同量级。这继续支持：target 更新是一次强重组事件，但不是 online 策略漂移的唯一解释。

### 4.4 reward 实际量级

| 站点 | 可读取正式选中结果数 | reward中位数 | 范围 | SY/该站中位数 |
|---|---:|---:|---:|---:|
| HLA | 0 | 缺失 | 缺失 | 不计算 |
| YC | 7 | 764.78 | 760.57–774.15 | 5.37 |
| FQ | 7 | 813.54 | 548.56–841.42 | 5.05 |
| LC | 3 | 616.58 | 566.12–626.41 | 6.66 |
| SY | 2 | 4108.85 | 4046.46–4171.24 | 1.00 |

现有标准化证据支持“SY reward 数值尺度明显较大”，但支持的具体范围是 **约为 YC/FQ/LC 中位数的 5.05–6.66 倍**，不是十倍。HLA 不能在当前统一审计范围内比较。

## 5. 结论

1. target 更新确实是一次较强的网络与 Q 排序重组事件；两种 seed 的更新窗口都出现大量 target 排序改变。
2. target 更新幅度不能单独解释策略下降或恢复：相近参数变化可对应差异很大的 Q 变化，且 target 冻结时 online 排序仍可大量漂移。
3. SY reward 尺度偏大获得了数据支持，但只能写成约 5–7 倍，不能写十倍。
4. reward 尺度目前仍是**待检验的参与因素**，不是已确认根因。
5. 观测空间缺少剩余预算等 Markov 信息仍是独立候选机制，本轮没有修改。

## 6. 下一步建议

可以进入一次显式 reward 缩放的最小验证，但必须分两级：

1. 新增项目本地、可选的统一缩放层，把完整 reward 的所有组成项一起乘以 0.1；不得只缩放产量项；
2. 同时保存 `raw_reward` 和 `training_reward`，防止经济解释和训练数值混淆；
3. 先做极短 smoke test，检查实际 env 返回值和 replay buffer reward 是否严格满足 `training_reward/raw_reward=0.1`；
4. smoke 通过后，才允许用 SY2014 seed1 做 25K 单变量对照；
5. 不在同一实验中改变观测空间、target interval、探索率、成本相对权重或其他超参数。
