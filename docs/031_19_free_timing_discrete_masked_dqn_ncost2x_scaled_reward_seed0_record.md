## Interpretation boundary

This is a single-seed training-stability smoke. It tests whether PPO value/policy learning is sensitive to reward magnitude under the same free-timing discrete action setup as 031_16.

Branch rules:

- If scaled reward materially improves timing/yield while preserving N economy, the next step is a cross-seed repeat of the same fixed configuration.
- If scaled reward only changes reward/loss magnitudes but still front-loads resources or underperforms the known staged reference, the bottleneck is not only numerical reward scale.
- This task must not be expanded to all sites/years from a single seed.

## Result interpretation

Branch: C relative to the current scaled-reward discrete MaskablePPO branch.

The fair DQN seed0 smoke completed successfully under the same free-timing discrete action grid, caps, interval constraints, and scaled reward used by 031_17.

Result:

- DQN seed0: Y=10678.77, I=156, N=240, simple profit=9322.77, PFP_N=44.49, N stress days=15.
- PPO seed0 from 031_17: Y=10943.10, I=108, N=240, simple profit=9635.10, PFP_N=45.60, N stress days=7.

The DQN policy did not collapse, and `mask_forced_noop_count=0` during deterministic masked evaluation, so the comparison was not invalidated by illegal-action masking. However, it remained clearly inferior to PPO seed0 in yield, irrigation economy, profit, and nitrogen stress. It also retained early-heavy nitrogen (N160 by DAP10).

Conclusion: under the current fair 20k seed0 smoke, DQN is usable but not competitive with the scaled-reward discrete MaskablePPO branch. Do not expand DQN to seed1/seed2 or all site-years unless a separate 100k DQN repeat is explicitly authorized.
