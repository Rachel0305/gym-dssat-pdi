# 2026-08-12 YC ent_coef=0.02 rescue

## Objective

Test whether the already-approved YC 2K candidate `ent_coef=0.02` avoids the late policy collapse observed for `learning_rate=1e-4` at 25K.

## Intervention contract

Only change `ent_coef` from `0.01` to `0.02`. Keep `learning_rate=3e-4`, `gamma=1`, `gae_lambda=1`, `n_steps=144`, `batch_size=144`, `n_epochs=5`, `clip_range=0.2`, `net_arch=[64,64]`, seed 0, lowIC input, 2004--2013 training years, 2014--2023 validation years, raw observation, no forecast, reward, safety and 16-action grid unchanged.

## Execution

- Use `nifty_taussig` and `/opt/gym_dssat_pdi/bin/python` only.
- Run one process, in an isolated output root, with 25,000 steps and fixed checkpoints 5K, 10K and 25K.
- Run dry-run and provenance checks first.
- Never overwrite 055, 065, or frozen 053 outputs; never run 100K.

## Gates

At every checkpoint record yield, irrigation, nitrogen, `PFP_N`, `WP_ET` if available, DAP1-after actions, cross-year signatures, non-zero action pairs, grid validity, request-to-safe, raw-to-safe and safe-to-DSSAT mismatch.

The 25K candidate passes only if: all ten validation years have daily output; all actions are on-grid; all transmission mismatches are zero; at least three non-zero action pairs occur; post-DAP1 actions occur in at least 8/10 years; and cross-year signatures are not a singleton. A yield collapse relative to 10K is a failure even if `PFP_N` rises only because inputs approach zero.

## Deliverables

Update `docs/2026-08-12_yc_ent002_rescue25k.md` and save an isolated machine-readable result. Do not commit or push.
